## 已核对的合同

- docs/12 的提交 ID、归属、正文规范化、冻结计划、逐项恢复与取消边界，与 Parser.ParseContextAt/PlanAt、SystemAction.IntentIndex 和 HTTP/WS 的调用链相符。解析时间锚来自任务 CreatedAt；入口角色与持久账号状态校验阻止停用用户继续写入。

## 发现与闭环

1. 持久账号不存在时鉴权应拒绝；修复后启动先加载账号，再事务保存缺失内置服务账号。独立测试代理已覆盖并发启动及数据库身份失败。
2. 日期自动归一化与含糊日期不得变成意外改期；根代理已收紧日期校验与确认语义，最终回归由测试代理负责。
3. 课堂跨标签切换账号后旧 WS/迟到 REST 可能保留或重新呈现前一账号的反馈正文。前端现将课堂生命周期绑定 lessonId、userId 和 token；旧连接回调同时检查当前身份与 token，清理未送达正文、计时器、TTS 和监听。静态复核通过，浏览器身份切换回归证据由前端代理提供。
   - 前端代理已报告 13/13 通过：web/.test-artifacts/closure-1791905117501-20140/results.json。随后补充的 handleFrame 顶层身份守卫、REST 帧闭包身份绑定与本地 ASR 身份变化取消，也已静态复核无阻断；最终重跑由该代理汇总。
4. 测试代理发现模型候选可把明文投诉误转为调量。依既定合同先隔离投诉分句，其他独立分句仍正常解析，最终候选去重；取消不转为处理成功。作者用例与独立红回归分别锁定混合输入保留和纯投诉不可写。此项实现由本评审者接手，因此独立批准与回归归测试代理，不能视为自审通过。
5. WS 显式 submission_id:null 原可降为匿名旧协议；已对齐 HTTP 严格输入拒绝，只有省略字段保留兼容。真实 WS 回归由测试代理新增，浏览器协议断言由前端代理维护。

- llmzhipu/client_unit_test.go 使用本地 httptest，覆盖请求模型/鉴权/结构化参数、成功解码、HTTP 错误、坏 JSON、空 choices、取消与传输错误；未发现外部密钥依赖或默认访问云的路径。
