# 本机课堂阶段验收（2026-11-12）

## 已通过的业务范围

本机 8090 平台提供英文 Piper TTS、中文 Sherpa TTS 与 Qwen3-ASR；未调用云端 ASR。双学生隔离真实媒体 Playwright 旅程 1/1 通过：两个独立账号和课程分别学习 `teacher/老师`、`apple/苹果`，各自 4/4 段实际 `playing→ended`、对应字幕、4 个唯一 ACK、英文和中文 ASR 均为 200、课报首答率 100%。首音为 1,722/1,678 ms，课程耗时约 29.7 秒。证据见 `two-student-real-media-20261112.md`。英文 `teacher/cat/apple` 的真人试听反馈为清楚、准确、自然。

语音合成或识别故障会暂停原课堂轮次，提供重试或文字输入，刷新/重连后不会把旧音频或旧结果推进到新轮次。Go 全量 26 包通过，相关包 `-race` 通过，`go vet ./...` 与前端构建通过；API、classroom、localmodel 覆盖率分别为 82.3%、90.2%、89.8%。恢复类 Playwright 全套 43/43 通过，其他专项为 basic 9/9、firstuse 1/1、feedback 27/27、journey 1/1；测试代码及验收明细见 `docs/03-测试用例.md` 与 `.test-artifacts/stage-acceptance/`。

## 仍未通过的范围

中文 TTS 常驻原型只运行在隔离端口 18002。其原生协议 5/5、fake HTTP 8/8、真实 HTTP 2/2、双学生取消串音浏览器 P06 1/1 均通过；N=8 的 800/800 请求成功。但 N=4/8 的 HTTP p95 为 **2,887/3,092 ms**，超过已冻结的 2 秒目标。混合 ASR/英文 TTS 负载、4/8 人真实浏览器首音/打断矩阵、真实 8090 supervisor 重启门和中文原型人工试听尚未执行，因此不得提升生产容量。完整数据见 `zh-tts-resident-isolated-20261112.md`。生产继续使用已验收的 `tts.maxConcurrent=2` 版本；隔离服务已停止。

真人隔离课堂试点尚未开展。按用户安排，它在其余开发与自动验证结束后才启动；现场需学生与麦克风/外放，重点记录插话与回声误触发、单字/混说/跳过、断网降级、复核乱序及首音和打断尾延迟。现有合成媒体测试不能替代真人试点。

## 当前决策

两名学生的本机业务闭环可复现；更高并发的目标和真人试点仍是独立验收项。本轮不切换生产 TTS，不把隔离原型结果当作正式课堂容量结论。所有提交均为本地提交，未推送远端。
