# 本轮验收方法记录

保留既有 `AGENTS.md` 不变；本轮可复用方法记录于此。各项结论仍以对应原始测试报告为准，本记录不替代质量门。

1. **复用结果必须证明输入相同。** 同时绑定生产源码、服务二进制、测试及夹具输入、原始报告路径和哈希、精确用例 ID。局部用例修改只能在证明其余代码与共享输入未变后，保留不受影响的完整已通过组。不得拼接失败用例的单独重跑来代替完整待验集合。
2. **先等待业务前置状态，再计目标行为时限。** 课堂入场、教学音频完成和开始跟读是不同阶段。麦克风或识别器用例应先证明已经进入采集阶段，再注入迟到回调、断线或换号；不能用拉长目标时限掩盖前置条件缺失。
3. **区分资源预算和产品延迟门。** 一组测试因进程总预算被终止，不等于产品响应延迟超标。保留失败与未完成记录，预先冻结完整待验集合、拆成固定批次，保持原单例时限、零重试及精确并集检查。
4. **格式测试必须证明模型响应确实到达。** 请求运输失败后规则兜底成功，只能证明运输降级，不能证明 malformed/null schema 被处理。分别断言请求计数、响应类别和用户结果；连接事件仅记固定摘要，不记录正文或密钥。
5. **浏览器时钟不控制服务端。** 冻结页面定时器后，真实服务端仍可能合法推进相位。用于隔离客户端行为的消息屏障必须有时间、数量及字节上限，保持顺序、暴露错误身份，并验证释放后的真实消息应用；结论不能外推为无屏障并发或物理音频性能。
6. **编译、用例执行和正式集成分别记账。** 整合脚本失败或编译失败的用例数为零；源码副本的 SQLite 测试通过不等于正式源码、全量回归或真实课堂通过。保存输入映射和失败历史，整合后重新验证。
7. **SQLite 名称与缓存按实际语义检查。** 对象命名空间检查必须考虑 SQLite 的 ASCII 大小写规则；未提交事务内的结构证明不能发布为全局缓存。当前授权数据不得复用结构缓存代替核查。
