# 本机 GPU ASR 接入验收（2026-11-12）

## 环境与边界

8090 模型管理平台登记 Qwen3-ASR-1.7B Q8_0、中文 TTS 和视觉文本模型；ASR 是独立 8001 进程，不在 8091 Picer.ModelServer 内。本轮用官方 llama.cpp b12167 CUDA 13.4 运行程序、现有本地 GGUF 权重，在 8001 启动 GPU ASR；8090 代理 `/api/asr/transcriptions` 正常。模型冷加载约 45 秒。当前进程由隔离试验启动，控制台显示 `unmanaged-ready`，不视为持久托管配置已验收。

## 冻结合成样本

数据源为 `review/audio-fixtures/manifest-zh.json`（12 条）与 `manifest.json`（16 条），均为独立合成 WAV；逐条原始结果见 `asr-gpu-20261112.json`。去空白与标点后，中文准确 9/12、英文 15/16。中文错例：安静→暗金、我想跳过→我想挑过、每课五十个词→每克五十格词；英文错例：book→Vog。它们与 CPU 版主要错误一致，GPU 加速没有改善模型识别质量。

热机后经 8090 代理，中文单次平均 176 ms、中位 152 ms、最大 482 ms；英文平均 154 ms、中位 145 ms、最大 210 ms。样本量小，最大值即最近秩样本 p95，不能代表多人课堂长尾或首音延迟。

## 产品路由

现有 opt-in Go 验收通过学生本人课堂转写路由：中文 12/12、英文 16/16 请求成功，供应商 HTTP 均为 200；产品路由中位耗时分别为 102 ms 和 95 ms。记录见 `asr-product-gpu-{zh,en}-20261112.json`。这只验证传输、权限和适配器，不将“有文本返回”计为语义正确。

## 剩余验收

当前中文关键跳过口令仍会误转写，不能宣称中文口令零漏检。真人麦克风、外放回声、背景人声、多人并发与长尾未在本轮合成样本中验证。真实课堂试点及模型质量决策须独立于本次 GPU 连通与时延结果。
