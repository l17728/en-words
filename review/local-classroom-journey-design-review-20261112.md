# 本机多词课堂设计评审（2026-11-12）

范围：`docs/78-local-classroom-journey-sdd.md` 的双学生多词旅程、ASR 故障恢复与“我会了／我不会”整句确认；同时核对 `docs/08-E2E测试方案.md` 的测试入口。评审只批准设计进入开发，不代表代码或真人试点验收。

| 评审视角 | 发现与收敛 |
| --- | --- |
| 架构、后端、安全 | Pilot v2 与现有 legacy 分期；双学生必须用隔离 SQLite/账号。下一课须在首课结算后由 learning due 卡产生，验非空 batch 与不同 ID。确认词不得跨相位授权，日志不写正文。修订后 P0/P1 为 0。 |
| 前端、测试、AI-Agent | `?e2e=1` 会禁自动 ASR 且无手动录音按钮，旅程改用正常 URL；后续文字轮次持有可控 `getUserMedia` 并在离 turn 时拒绝。final 打乱词序，按当前题选答；503 与独立迟到响应分案。六条英文 WAV 的标签和 SHA 已与冻结 manifest 核对。修订后 P0 为 0。 |
| 语义与负向控制 | 原 `judge`/`voicecmd` 去掉所有 Unicode 标点，会把问句、引号或词内逗号误归一化成确认。规格要求先锁定红灯，再统一收紧完整短句语法，并验证正负自述、两次机会、重复和迟到。 |

实施验收必须保留 Go 逻辑/并发与 Playwright 用户旅程两类测试；本机合成 WAV 的通过不等于真人语音质量。多学生 4/8 人首音容量、文本模型长跑稳定性与真人课堂另按既有规格验收，不得并入本设计评审的“通过”。
