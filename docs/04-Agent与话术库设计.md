## 1. Agent 总则

### 1.1 双 Agent 职责边界

| | 老师 Agent | 系统 Agent |
|---|---|---|
| 场域 | 课堂内（实时，事件驱动） | 课后/课间（事务，触发驱动） |
| 关心 | 此刻教学体验：节奏、鼓励、纠错 | 长期学习效果：排课、调参、反馈 |
| 可用工具 | classroom.* / scripts.* | scheduler.* / feedback.* / config.* / progress.query / scripts.* |
| 失败兜底 | 状态机超时矩阵自动推进（Agent 卡死不卡课堂） | 模型解析失败走规则兜底；取消保留待恢复；不可执行计划终止，事务按未完成项幂等恢复 |

### 1.2 决策通用约束

1. LLM 决策输出 = `{say?: 话术, tool_calls: [...]}`；平台执行工具并回观察结果。
2. 每轮工具调用 ≤8 次、总时长 ≤60s（Guard）。
3. `advance_phase` 只能命中状态机当前合法迁移（平台强校验）。
4. 话术**必须**来自话术库模板 + 口语化规则（§6），禁止 LLM 即兴长篇——保持人设一致与内容安全。
   **校验与降级**（评审发现 AI-02）：LLM 输出校验失败（非法 template_id / 自由发挥 / 超 60 字）→ 服务端降级为 `scripts.pick` 确定性抽取的模板原文，并记审计。
5. 鼓励/纠错密度由配置 `encourageEveryN` 控制，防止过密（每 3 词夸一次=烦）。

## 2. 老师 Agent：决策表

> 事件 →（上下文）→ 动作序列。所有动作经 §3 超时矩阵兜底。

| # | 事件 | 上下文条件 | 动作序列（工具调用 + 话术） |
|---|---|---|---|
| T-01 | lesson_started | 首课 | say(open+自我介绍+称呼昵称) → show_word(词1, 中英对照) |
| T-02 | lesson_started | 非首课 | say(open+上次成绩一句话) → show_word(词1) |
| T-03 | word_shown（学生点击或 0.8s 自动开读） | — | play_tts(en×repeatTimes, 间隔 ttsIntervalMs) → play_tts(zh释义×1) → start_repeat(1遍, 老师听读判读) |
| T-04 | repeat_done（听读判读通过） | 本课还有词 | say(transition_word, 30%概率) → show_word(下一词) |
| T-05 | repeat_done（听读判读通过） | 本课最后一词 | 触发 teaching_completed（2026-08-25 定案：教学中零测试，教完才测） |
| T-06 | repeat_timeout | 第1次 | say(nudge_repeat 轻提醒) → 继续听读 |
| T-07 | repeat_timeout | 第2次 | 计为完成，自动推进下一词（不阻塞课堂） |
| T-08 | student_answered | 判分 correct | show_feedback_ui(check) → say(praise, 按密度配置) → 下一题 |
| T-09 | student_answered | 判分 near（近似对） | show_feedback_ui(check) → say(gentle_correct 提示标准义) → 下一题 |
| T-10 | student_answered | 判分 wrong 且该词第1次错 | show_feedback_ui(cross) → **RETEACH 完整闭环**（R2-AI-04）：show_word(含中文) → play_tts(zh释义×1) → play_tts(en×1) → start_repeat(1遍) → say(reassure) → RETEST 同词（D-20：每词最多 2 次机会） |
| T-11 | student_answered | 判分 wrong 且该词第2次错（或学生说"不会"） | show_feedback_ui(cross) → say(no_worries) → 记未掌握，跳下一题（不再重测） |
| T-12 | teaching_completed（全部词教完） | — | say(transition_to_quiz) → start_quiz(kind=final, 池=本课全部词 Fisher-Yates 打乱, seed=lessonId×31+bookId) |
| T-13 | quiz_completed（final） | 有打叉词 | say(transition_review) → start_review(轻量回顾: 中文大字+自动播英文, 无重测) |
| T-14 | quiz_completed（final） | 无打叉词 | say(strong_praise) → T-16 |
| T-15 | review 完成 | — | say(review_closing) → T-16 |
| T-16 | 全部完成 | — | say(closing + 本课数据总结 + 预告下次) → advance_phase(LESSON_END) |
| T-17 | phase_timeout(作答) | 第1次超时 | say(nudge_answer) → 等待再 20s |
| T-18 | phase_timeout(作答) | 第2次超时 | 判 wrong → 按机会计数走 T-10/T-11 |
| T-19 | state_restored（重连） | — | say(reconnect 安抚一句) → 恢复当前环节 |
| T-20 | 学生连对 ≥5 | 节奏正常 | say(streak_praise)（每课最多2次） |

**Mock 实现要点**：脚本 = 该表的条件机直接代码化；话术槽从话术库按 weight 随机；口语化规则跑 §6 固定管线。确定性可测。

## 3. 老师 Agent：节奏与超时

### 3.1 节奏原则（用户要求：稍快、不停顿过长）

- **默认推进不等确认**：TTS 播完自动进跟读；跟读判读通过自动进下一词（0.8s 间隔）。
- **等待只在需要学生动作处**：展示单词（0.8s 自动开读，点击可提前）、跟读（10s 听读判读窗口）、作答（20s）。
- 超时第一处理永远是**温和话术**，第二处理才**跳过推进**，且跳过项记录为待复习（E-记录）。
- 组间/环节转场停留 1.2s（转场话术+动画），不打断感。

### 3.2 鼓励密度控制

```
encourageEveryN=8（默认，可配 [3,20]）
计数器: 自上次鼓励后完成的词数 ≥ N 且本次判对 → 触发鼓励
连对≥5 触发 streak_praise（每课上限2次，独立计数器）
答错后 1 个词内必有 reassure（缓冲挫败感）
```

## 4. 系统 Agent：决策表

| # | 触发 | 上下文 | 决策动作 |
|---|---|---|---|
| S-01 | lesson_finished | 正确率 ≥85% 且无逾期 | plan_next_lesson（正常阶梯）；若连续3课 ≥90% 且 wordsPerLesson<100 → 建议加量（需确认话术） |
| S-02 | lesson_finished | 正确率 60~85% | plan_next_lesson（阶梯不前进=同级重走一次）；不加量 |
| S-03 | lesson_finished | 正确率 <60% | plan_next_lesson（阶梯后退一级，最低 step=0）+ wordsPerLesson 下调 10%（不低于40）+ 回复安慰+建议 |
| S-04 | lesson_finished | 平均作答 >15s（偏慢） | 下批新词占比降至 40%（更多复习词） |
| S-05 | feedback_submitted | 意图 A/B/C（词量/频率） | apply_adjustment（边界内）→ reply(确认+新值)；超界 → need_confirm 话术 |
| S-06 | feedback_submitted | 意图 D（推迟） | 校验 ≤7天/月≤3次 → postpone_lesson → reply(新时间)；冲突则 propose 备选日 |
| S-07 | feedback_submitted | 意图 E（难词） | 标 BoostFlag（池≤20，FIFO）→ reply |
| S-08 | feedback_submitted | 意图 F（投诉） | escalate + reply(已记录安抚) |
| S-09 | feedback_submitted | confidence<0.6 | reply(追问澄清一次)；再不明 → escalate |
| S-10 | cron 逾期 | lesson 过期 | postpone_lesson(次日) + 通知；若连续 2 次逾期 → 主动反馈式询问（"最近是不是时间紧？"）+ 建议 |
| S-11 | cron 逾期 | 连续 3 次逾期 | 建议暂停计划（待确认），防挫败流失 |
| S-12 | feedback_submitted | 多意图（R2-FE-04） | 拆分为意图数组 → 按 S-05..S-10 逐项执行 → 合并回复（FR-11 模板）；任一项 need_confirm 则整体 need_confirm，已应用项不回滚（逐项独立提交） |
| S-13 | lesson_finished | **记忆曲线审视**（D-13） | 读课报记忆曲线对照字段：① 到期复习完成率 <80% → 下批 due 优先且 new 降至 0.4W；② 逾期词 >10 → 主动建议学生固定时段（FR-9 关怀话术）；③ LadderHealth <0.6（大量词卡低阶重走）→ 输出"阶梯粘滞"告警至审计+建议教师放慢（new 再降档） |
| S-14 | lesson_finished | 薄弱词处置（D-13） | WeakMeaningWords(RETEACH≥2) → 逐词标 BoostFlag（下节优先+加密测试）并入课报建议段 |
| S-15 | lesson_finished | 课报生成与推送（D-13） | 聚合跨课数据（CumLearned/Trend）→ 组装 LessonReport → ① 交话术层渲染老师三段式总结（RB 模板）② 写 lessons.result ③ 通知中心推送 ④ 计划视图更新 |

> **多意图反馈**（评审发现 AI-06，FR-G2）：如"太多了而且周三有事"→ 先拆分为意图数组 `[A, D]` → 逐项按上表处理 → 合并成一条回复；任一项超界则该项走 need_confirm，其余照常应用。

## 6. 口语化规则引擎

> 目标：模板为核、实时微调，避免机器人腔（用户要求）。管线固定，Mock/真实 LLM 共用。

```
render(category, ctx):
 1. 按 weight 随机选模板（同课已用过的降权，避免重复）
 2. 变量替换 {name}{word}{n}...
 3. 口语化微调（按优先级，每次随机启用 0~2 条，保证同模板两次输出不完全一样）：
    a. 语气词注入（30%）：句首加 "来，/ 好嘞，/ 嗯——/ 哎，" 之一
    b. 称呼变体（25%）：{name} → 昵称/ "同学"/ 省略 轮换
    c. 口头禅裁剪（20%）：句号前加 "哈 / 呗 / 啦" 匹配语气
    d. 长句拆短（模板>25字时 40%）：在逗号处断成两句
    e. 数字口语化（15%）："3 个"→"三个"；"85%"→"八成五"
 4. 安全校验：输出长度 ≤60 字；无未替换占位符；否则回退原始模板
```

**约束**：微调只改"皮"不改"核"（信息量：数字/日期/词义必须保留）；每次 render 结果连同模板 id 记审计，供 E2E 断言与话术质量分析。

### 剩余策略持久闭环设计（2026-10-14，待实施复核）

平台每30分钟只扫描候选，不作教学决策。候选条件为 scheduled 且未结课，超过 openAt+overdueHours；存在可续课堂时采用 SDD 的48小时续课上限，不能将仍在有效答题的课堂改期。传入 SystemAgent 的事实包括学生/词库/课程、冻结 openAt、检测时刻、最近成功完成课后的连续逾期计数。计数按该学生该词库时间顺序计算，成功结课重置；重复扫描同一课程不递增。

| 条件 | Agent决策 | 原子执行事实 |
|---|---|---|
| 第1次逾期 | expire + 次日同本地时段重排 + 通知 | 旧课 expired；新课保留原批次；词卡 LadderStep/LastReviewAt 不变 |
| 第2次连续逾期 | 同上 + FR-9关怀及调整建议 | 建议只作通知，不自动减量/暂停 |
| 第3次及以后连续逾期 | 同上 + 建议暂停（待学生确认） | 未确认仍保留重排；不可直接标记学生暂停 |
| 已被手工改期/结课/删除或仍有效在课 | stale/no-op | 不创建重复课程或通知，不消耗次数 |

“次日”相对检测日取下一日，并保持原计划的本地时分，避免停机多天恢复后重排到过去。同学生同词库存在另一有效 scheduled 课时返回 conflict 提示管理员，不能覆盖该课；冲突处理与已成功动作分开留痕。禁止接通旧 HandleOverdue 直接策略路径。持久 task 唯一键为 `(lesson_id,原open_at,policy_version)`；首次事务冻结计数/策略/目标时刻，执行事务重验课程原状态和时间，完成 receipt、旧课状态、新课及通知、工具审计一并提交。失败回滚可重试，重启/双实例重放读同 receipt；每个任务共享8调用预算及稳定 trace_id，记录 overdue_detected/agent_decision/overdue_replanned/overdue_conflict，日志不含课堂原文。
