## 1. Agent 总则

### 1.1 双 Agent 职责边界

| | 老师 Agent | 系统 Agent |
|---|---|---|
| 场域 | 课堂内（实时，事件驱动） | 课后/课间（事务，触发驱动） |
| 关心 | 此刻教学体验：节奏、鼓励、纠错 | 长期学习效果：排课、调参、反馈 |
| 可用工具 | classroom.* / scripts.* | scheduler.* / feedback.* / config.* / progress.query / scripts.* |
| 失败兜底 | 状态机超时矩阵自动推进（Agent 卡死不卡课堂） | 事务幂等重试；解析失败→escalate |

### 1.2 决策通用约束

1. LLM 决策输出 = `{say?: 话术, tool_calls: [...]}`；平台执行工具并回观察结果。
2. 每轮工具调用 ≤8 次、总时长 ≤60s（Guard）。
3. `advance_phase` 只能命中状态机当前合法迁移（平台强校验）。
4. 话术**必须**来自话术库模板 + 口语化规则（§6），禁止 LLM 即兴长篇——保持人设一致与内容安全。
   **校验与降级**（评审发现 AI-02）：LLM 输出校验失败（非法 template_id / 自由发挥 / 超 60 字）→ 服务端降级为 `scripts.pick` 确定性抽取的模板原文，并记审计。
5. 鼓励/纠错密度由配置 `encourageEveryN` 控制，防止过密（每 3 词夸一次=烦）。

| T-06 | repeat_timeout | 第1次 | say(nudge_repeat 轻提醒) → 重开 start_repeat 当遍 |
| T-07 | repeat_timeout | 第2次 | say(nudge_repeat 更温和) → 计为完成，推进下一遍/词 |

| T-11 | quiz_completed（小测） | 本课还有组 | say(transition_group + 组小结一句) → show_word(下组词1) |
| T-12 | quiz_completed（小测） | 本组序号 ≥2 | 综合测试 → start_quiz(此前所有组未毕业词, 打乱) |
| T-13 | quiz_completed（综合） | 有打叉词 | say(transition_review) → start_review(打叉词) → 重测至对 |
| T-14 | quiz_completed（综合） | 无打叉词 | say(strong_praise) → 下组词1 |
| T-15 | final_test 完成 | 有打叉 | start_review(打叉) → 重测 → 全对后 T-16 |
| T-16 | 全部完成 | — | say(closing + 本课数据总结 + 预告下次) → advance_phase(LESSON_END) |

## 3. 老师 Agent：节奏与超时

### 3.1 节奏原则（用户要求：稍快、不停顿过长）

- **默认推进不等确认**：TTS 播完自动进跟读；跟读完成自动进下一词（0.8s 间隔）。
- **等待只在需要学生动作处**：点击单词（8s）、跟读（每遍 10s）、作答（20s）。
- 超时第一处理永远是**温和话术**，第二处理才**跳过推进**，且跳过项记录为待复习（E-记录）。
- 组间/环节转场停留 1.2s（转场话术+动画），不打断感。

### 3.2 鼓励密度控制

```
encourageEveryN=8（默认，可配 [3,20]）
计数器: 自上次鼓励后完成的词数 ≥ N 且本次判对 → 触发鼓励
连对≥5 触发 streak_praise（每课上限2次，独立计数器）
答错后 1 个词内必有 reassure（缓冲挫败感）
```

| S-01 | lesson_finished | 正确率 ≥85% 且无逾期 | plan_next_lesson（正常阶梯）；若连续3课 ≥90% 且 wordsPerLesson<100 → 建议加量（需确认话术） |
| S-02 | lesson_finished | 正确率 60~85% | plan_next_lesson（阶梯不前进=同级重走一次）；不加量 |
| S-03 | lesson_finished | 正确率 <60% | plan_next_lesson（阶梯后退一级，最低 step=0）+ wordsPerLesson 下调 10%（不低于40）+ 回复安慰+建议 |
| S-04 | lesson_finished | 平均作答 >15s（偏慢） | 下批新词占比降至 40%（更多复习词） |
| S-05 | feedback_submitted | 意图 A/B/C（词量/频率） | apply_adjustment（边界内）→ reply(确认+新值)；超界 → need_confirm 话术 |
| S-06 | feedback_submitted | 意图 D（推迟） | 校验 ≤7天/月≤3次 → postpone_lesson → reply(新时间)；冲突则 propose 备选日 |
| S-07 | feedback_submitted | 意图 E（难词） | 标 BoostFlag（池≤20，FIFO）→ reply |
| S-08 | feedback_submitted | 意图 F（投诉） | escalate + reply(已记录安抚) |
| S-09 | feedback_submitted | confidence<0.6 | reply(追问澄清一次)；再不明 → escalate |
| S-10 | cron 逾期 | lesson 过期 | postpone_lesson(次日) + 通知；若连续 2 次逾期 → 主动反馈式询问（"最近是不是时间紧？"）+ 建议 |
| S-11 | cron 逾期 | 连续 3 次逾期 | 建议暂停计划（待确认），防挫败流失 |
| S-12 | feedback_submitted | 多意图（R2-FE-04） | 拆分为意图数组 → 按 S-05..S-10 逐项执行 → 合并回复（FR-11 模板）；任一项 need_confirm 则整体 need_confirm，已应用项不回滚（逐项独立提交） |
| S-13 | lesson_finished | **记忆曲线审视**（D-13） | 读课报记忆曲线对照字段：① 到期复习完成率 <80% → 下批 due 优先且 new 降至 0.4W；② 逾期词 >10 → 主动建议学生固定时段（FR-9 关怀话术）；③ LadderHealth <0.6（大量词卡低阶重走）→ 输出"阶梯粘滞"告警至审计+建议教师放慢（new 再降档） |
| S-14 | lesson_finished | 薄弱词处置（D-13） | WeakMeaningWords(RETEACH≥2) → 逐词标 BoostFlag（下节优先+加密测试）并入课报建议段 |
| S-15 | lesson_finished | 课报生成与推送（D-13） | 聚合跨课数据（CumLearned/Trend）→ 组装 LessonReport → ① 交话术层渲染老师三段式总结（RB 模板）② 写 lessons.result ③ 通知中心推送 ④ 计划视图更新 |

> **多意图反馈**（评审发现 AI-06，FR-G2）：如"太多了而且周三有事"→ 先拆分为意图数组 `[A, D]` → 逐项按上表处理 → 合并成一条回复；任一项超界则该项走 need_confirm，其余照常应用。

## 6. 口语化规则引擎

> 目标：模板为核、实时微调，避免机器人腔（用户要求）。管线固定，Mock/真实 LLM 共用。

```
render(category, ctx):
 1. 按 weight 随机选模板（同课已用过的降权，避免重复）
 2. 变量替换 {name}{word}{n}...
 3. 口语化微调（按优先级，每次随机启用 0~2 条，保证同模板两次输出不完全一样）：
    a. 语气词注入（30%）：句首加 "来，/ 好嘞，/ 嗯——/ 哎，" 之一
    b. 称呼变体（25%）：{name} → 昵称/ "同学"/ 省略 轮换
    c. 口头禅裁剪（20%）：句号前加 "哈 / 呗 / 啦" 匹配语气
    d. 长句拆短（模板>25字时 40%）：在逗号处断成两句
    e. 数字口语化（15%）："3 个"→"三个"；"85%"→"八成五"
 4. 安全校验：输出长度 ≤60 字；无未替换占位符；否则回退原始模板
```

**约束**：微调只改"皮"不改"核"（信息量：数字/日期/词义必须保留）；每次 render 结果连同模板 id 记审计，供 E2E 断言与话术质量分析。
