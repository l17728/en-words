# 32 全双工课堂特性规格（设计初稿，未批准实施）

2026-10-15。范围：浏览器采集与实际回放、流式快路与独立复核、插话和说话权、字幕及教学提交、远程模型接入、隔离试点与回退。用户要求完整设计与各领域评审达成一致后开发；本稿不是上线承诺。根代理宣布设计通过前，不修改产品代码、不运行新模型或切换服务。

## 1. 当前事实与目标

当前`web/src/audio/local.ts`请求AEC/NS，MediaRecorder有限录制4秒后转16kHz单声道WAV再请求转写；不是持续流式全双工。浏览器约束请求不证明设备真正启用AEC/NS，更不证明外放回声已消除。现有实际播放字幕、播放成功ACK、媒体总期限和会话隔离必须保留。

`api/ingress.go`当前TurnContext由相位、题目、段号等组成；`roomcontext.go`把L2网络调用放在Room锁外，返回后重验pending、epoch/turn、暂停和退休。`classroom.applyJudge`以QuizItemID幂等执行判分。全双工必须在这些安全门之上增加语音会话，不允许将模型回调直接接到状态机。

不改变D-20每词最多两次机会、D-21先教全部词再final、默认3英1中及用户配置、RETEACH、跟读通过推进、明确跳过/不会等既有决策。老师Agent负责何时接纳回答、澄清、重教和推进；平台负责权限、媒体、版本、幂等、预算与实际效果工具。新增决策必须同步docs04，不在前端或模型适配器暗置教学政策。

目标是外放时可听见学生插话，低延迟呈现稳定草稿和安全接话，同时只有已确认的最终输入/裁决可以消耗机会、改掌握、改配置或推进课堂。不是“任何音频同时播放/录制就算全双工”。

## 2. 能力与模型假设

远程`/root/ai-full-duplex-design.md`是待根代理核实的来源，本稿未访问远程文件。MiniCPM-o 4.5快路、Qwen3-Omni异步复核仅为草案候选，未确认具体revision、许可、输入输出模态、实时会话API、音频分块格式、取消能力、资源和并发极限。不得把OpenAI兼容文字接口推断成支持实时双向音频。

上线前产生能力清单：浏览器/设备、secure context与麦克风权限、getSupportedConstraints与track.getSettings实际值、AudioContext采样率、AEC/NS/AGC请求和实测、可用传输、服务模型标识/revision、音频格式、流式事件及结束标记、取消后GPU任务释放证据。unsupported与实际关闭必须单列；AGC可关闭避免截幅/强噪声放大，不宣称始终有益。

快路不是权威教师：用于流式转写/语音活动推测和可取消的中性接话。复核路独立接收本次完整音频和冻结题目事实，输出严格schema的最终转写及判分建议。复核路是否真具备独立声学输入能力由实测决定；若只看快路文字，必须标为文本复核，不能声称独立ASR交叉验证。两个模型共享权重/转写时的相关错误不能按两票算置信度。

## 3. 媒体处理与端点检测

### 3.1 采集链

一个课堂一次麦克风授权、一个活动采集管线。实际权限成功与track alive后才显示监听；用户可随时静音/退出。计划使用AudioWorklet产生有序PCM小块，若浏览器不支持则保持现有有限录音/文字路径，不能伪称流式开启。只有用户进入已授权课堂并主动启用才持续采集。

共识参数：帧20ms、批次80ms、单声道16kHz、前滚300ms、尾留200ms、终点静音600ms、单句最多15s、课堂待复核最多1句。禁止未协商重采样或转码。每块带单调seq与相对采样时间，限制块大小/总时长/队列字节数；丢块、乱序或溢出明确中止该utterance，不拼接成完整回答。变更这些参数须版本化并重新评审/对照，不允许测试中临时调参取绿。

### 3.2 VAD与endpointing

VAD只回答“可能有学生声音”，不判断答案和教学意图。起音候选窗口100ms，结合回声抑制门，前滚保留完整短词；100ms不是删除短于该时长词语的过滤器。端点候选静音600ms、保留200ms尾音。短停顿后恢复说话可在尚未提交前撤销端点候选，但不重置15秒总上限；到硬上限提示重说，不把截断尾音静默交最终判分。

静音、外放回声、咳嗽、敲键盘、另一人说话分别测试。未经验证的“说话人身份模型”不得作为鉴权；账号授权仍由服务端。无可验证AEC的设备默认耳机/按住说话试点，不偷偷将完整外放当学生答案。

只有稳定endpoint才冻结完整audio hash、时长、seq范围，发起一次最终复核。快路partial变更不会重复提交复核；断流不等于用户说完。网络静默超时显示未提交/可重试，不能按答错消费机会。

## 4. 说话权、插话与课堂时间

说话权与课堂phase分离，服务端仲裁`teacher_speaking / student_speaking / awaiting_verification / idle`；客户端仅可本地紧急停声以降低插话延迟，不能由此自行迁移课堂。一个output lease对应一段实际音频，任意时刻最多一个可听输出；学生有效插话优先，快路和复核模型不得各自同时播放。

本地起音候选触发即撤销当前output lease并停止Audio/原生TTS/流式音频缓冲，立即清字幕和发送取消请求，不duck后继续播放等待服务端确认。被撤销lease的onended/onstart/网络尾块永久无权。**cancel不等于tts_finished**，不得递增朗读次数、当作已教完或计入掌握。纯VAD停声不是教学pause，不直接冻结成绩或改变机会数；错误起音由Agent依据租约和最终事实决定恢复。

服务端取消确认后冻结该段播放义务。Agent依据已确认插话结果决定：控制口令执行既有工具；提问/不清输入先澄清，再从被中断段开头恢复；普通答案仅在允许答题/跟读的冻结上下文接纳。初版不做音频字级续播；实际已经完成的段不重复，中断段需重新完成一次。未获最终确认的“跳过/不会/减量”等partial不得执行。

VAD本身不调用长期暂停。服务端确认有效起音后，Teacher试点策略可为同一input_revision授予最多一次语音活动租约，冻结授予时原剩余作答时间，不重置原timeout。租约硬上限15s输入+8s确认计算；partial、噪音、撤销后重说、重复起音及endpoint撤销均不能刷新或再次授予同revision。失效/网络故障不算答错，恢复原剩余时间后沿原超时策略运行；没有剩余时间时不能赠送新完整答题窗口。具体合同写入docs04试点表，未启用模式完全保留旧策略。

## 5. 稳定回答身份与两阶段提交

新增语音会话身份独立于相位派生的旧turn字符串：`session_generation + lesson_epoch + input_revision + utterance_id`。其中input_revision由服务端在实际题目、机会、学生显式撤答或授权变化时递增；partial字幕、neutral preview、进入awaiting_verification不改变它。不可直接使用每帧caption版本或playback段变化作为回答身份，否则每次preview都把合法最终复核变成stale。

服务端收到开始语音时冻结当前允许输入的题目事实：lesson/student/book、QuizItemID（含round/seq）、phase用途、参考答案版本、input_revision、授权连接代次及截止时刻；返回不可伪造的服务端ticket引用。endpoint固定音频，原utterance进入`finalizing`。相位可显示等待确认，但最终提交要比较冻结的**逻辑回答身份**，不能拿已经变成judging的旧UI turn字符串机械拒绝。

建议状态：`listening → speech_candidate → capturing → endpoint_pending → finalizing → verified → committed`；分支`cancelled / rejected / timed_out / conflict`均不可提交。每句只允许一个最终提交receipt，唯一键绑定lesson+epoch+input_revision（不含utterance）；持久提交成功才ack，重发仅返回同receipt，不二次判分/消费机会。用户修正文字应生成明确revision，不能覆盖已committed记录。

最终提交同时重验当前登录/选库、课堂有效与未退休、逻辑题目和机会未变、无手动文字回答先提交、utterance未取消、模型响应schema与audio hash关联有效。旧epoch、旧题、换号、已退休、重复final、晚到复核只能记录固定stale原因，不写新题。若用户已经手动提交，音频复核不能改写该结果或追补第二次机会。状态迁移先在隔离副本计算，checkpoint/receipt/工具审计/outbox同事务成功后才发布Room内存；数据库回滚不能留下已经变题的内存。

重启/断线：已持久committed可查receipt恢复；尚未提交的流式音频不跨新连接隐式重放，旧任务取消并进入可见重说状态。快路partial不持久化为学习记录。是否允许同epoch重连继续同句在首版明确不支持，避免半句拼接。

## 6. 快路预览与最终确认的分歧

| 情形 | 允许呈现 | 教学副作用 |
| --- | --- | --- |
| 快路partial | 学生侧标记“识别中”的可修订字幕 | 无 |
| 快路认为句子结束但复核未完成 | 固定中性“我听到了，正在确认”等可取消模板，或静默进度 | 无评价、无答案泄露、无奖励/重教/配置改变 |
| 两路完整结果在保守归一化后完全一致，最终schema/上下文有效 | 转为最终学生字幕；Teacher基于最终结果调用既有工具 | 一次提交后按既有D-20/D-21执行 |
| 两路仅NFC、大小写、空白或单个终末句号不同 | 仅下述固定归一化可合并，保留原始revision事实 | 仍仅最终一次 |
| 意义、否定、数字、指代、控制意图或判分相冲突 | 显示需确认，让学生重说或明确确认最终文字 | 不消耗机会，不按多数票猜答案 |
| 复核超时/故障/坏schema | 保留未提交草稿、错误与重试/文字入口 | 不把快路升级为权威；不默认wrong/correct |

首版只允许Unicode NFC规范化、Unicode小写、首尾空白清除与连续空白折叠、仅单个终末中英文句号（. 或 。）清除；连续多个句号、问号、感叹号、省略号和逗号保持原样；只有上述规范化后完全一致才可合并；不删除内部标点，不做NFKC兼容折叠，不删除否定/数字，不做同音、同义、数词或语言翻译映射。其他任何不一致一律needs_confirmation，即使人看来可能同义，也不能交未定义语义fixedrules猜测。分别报告双轨完成率、归一化一致率、确认率和确认放弃率，不能只统计自动提交子集。单轨缺失/超时不能冒充双轨一致；保留草稿，走明确用户文字确认/现有文字路径。复核路不是自动真理，独立质量门未过不得自动判教学。学生确认仅确认所说文字，不能直接确认自己答对；之后仍走Judge/Teacher，声学复核和判分合并调用也须分开记录事实。

未确认模型话术不播放。若未来要求自由快路语音回答，只能在隔离试点独立安全/教学质量审核后扩展；本版中性模板不接受模型任意文本。因此快路有可见即时字幕/安全接话收益，但不会先说“你答对了”再反悔。流式生成可以内部投机，但不得对用户发出未经确认的评价。

端点到最终确认计算使用同一个8秒绝对deadline，包含排队、声学复核与可能的现有Judge调用；若分两次模型调用，只传剩余预算，不能每次重新给8秒。最终事务与输出耗时另记录，不能拿推理deadline冒充持久提交完成期限；如果提交前预算已过，不启动新教学提交。预算内已进入提交仍以实际commit结果/receipt为准，不能取消后假称未写。

## 7. 字幕与实际声音一致

字幕分轨：学生`draft/final/needs_confirmation`与老师`planned/playing/ended/cancelled`。学生partial只更新同utterance较新revision，final后迟到draft拒绝；取消和新题清除旧草稿或转入明确历史区，不伪装当前输入。

老师字幕仅实际playing/onstart后显示该已授权段文字，排队/加载时不显示为正在朗读。流式音频若不能可靠提供文本与音频chunk对齐，先采用完整已确认短句再流式播放，不虚构逐字卡拉OK。插话清除字幕与音频使用同一lease，结束回调只在lease有效且确实完成时发ACK。

## 8. 传输、权限、资源与远程接入

33负责协议细化：控制通道保留鉴权/心跳/可取消的有界worker，音频通道与慢推理任务隔离；每个流有session ticket、seq、最大帧/句/队列与deadline，反压溢出明确停止而非无限缓存。不能让音频上传阻塞心跳，也不能为每帧无限goroutine。cancel先撤销写权再尽力取消上游；取消请求成功不代表GPU已停止，需观察服务侧任务释放。

远程SSH必须经受控跳转主机，host key验证、最小权限服务账号、固定目标/端口，凭据只在本机受保护配置，不能发到浏览器/日志/仓库。模型端口优先仅回环绑定，通过隧道供后端适配器访问；禁止打开公网免鉴权推理口或关闭SSH主机校验。连接、隧道及模型生命周期分别记录，重连不得自动切换模型/供应商。

新增OpenAI兼容模型注册在后端提供商适配层，分别声明text/chat、audio stream、transcription等已验证能力；不得将同一base URL路径硬套所有模态。固定model ID/revision及协议版本，严格JSON/schema、输出长度、超时、错误与取消合同。支持流只表示传输能力，不代表模型质量通过。接入不自动替换现有生产文本/ASR/TTS，也不因兼容API而绕过Agent工具注册与审计。

日志：沿lesson trace关联session/utterance/input_revision/output_lease/model_revision，以固定事件记录capture_started/endpoint/preview/final_requested/final_verified/conflict/commit/stale/barge_in/cancel_requested/cancel_effective/fallback及耗时、字节、seq缺口。默认不记音频/完整转写/提示词/token/SSH命令；质量夹具按明确授权独立保存哈希和人工标签。

## 9. 隔离试点、部署与回退

Feature flag默认关闭，按管理员明确指定的测试账号/课堂启用；服务端校验，查询参数不能绕过。旧单工链路及文字输入继续可用。新配置版本、模型revision、协议与数据迁移先在独立DB/端口/账号验证，不直接在现有课堂切换。

模式转换只在无未提交回答且无活动播放的边界进行；手动关闭/断线时立即撤销全部流和lease，待媒体释放后回旧路径。无法干净释放时显示停止/重连，不能旧新两条录音或两条TTS同时运行。回滚不删除已提交学习记录，不重放未确认音频；新receipt使用版本化可读记录，旧服务不能理解时必须先排空/停止试点，不能静默丢弃。

模型远程部署或共享服务重启需根代理在具体方案、配置/文件hash、备份和精确服务影响可审后统一执行；本稿不授权任意停机/下载或切换。用户已授权本轮开发不等于免除设计门。
