## 1. 测试策略总览

| 层 | 工具 | 范围 | 准入 |
|---|---|---|---|
| 单元测试 | Go `testing` / 前端 vitest | 状态机、调度器、判分器、配置边界、意图解析、VAD 算法（纯函数抽取）、WS seq 去重 | 提交必绿 |
| 集成测试 | Go httptest + 内存 SQLite | REST/WS/工具管线/审计/事务 | 提交必绿 |
| 多用户 E2E（服务级） | Go 并发测试：多学生 WS 客户端池 + Agent(Mock) + 管理员 REST | 全链路拟真 | 发布必绿 |
| 浏览器 E2E | Playwright | 关键 UI 流：摸底/课堂/反馈/管理后台 | 发布必绿 |
| 专项 | 覆盖率脚本 / 日志断言 / 恢复演练 | 见 §5 | 发布必绿 |

**Mock 原则**：LLM/TTS/ASR 全走 Provider 接口的确定性 Mock（见 05 文档），每条 E2E 用例声明所需 Mock 脚本号，保证可复现。

## 4. 多用户拟真 E2E 用例（质量铁律 5）

> **并发在场**：学生×3 + 管理员 + 老师 Agent + 系统 Agent 同时活动，按拟真时序编排，非单接口冒烟。服务级用 Go 并发驱动，浏览器级用 Playwright 多 context。

### E2E-01「三学生并发完整学习日」

```
配置: 学生 S1/S2/S3，各自词库(初一/初三/高三)，Mock LLM/TTS/ASR 脚本集
时序(T+相对分钟):
 0   admin 登录，批量导入 3 个词库（各200词，含格式脏数据），发布
 5   S1/S2/S3 并行登录，各自选库、摸底（勾选率分别 10%/30%/5%）
 8   三人同时进入各自首课（Mock Agent 驱动）
     - S1 正常跟读作答（脚本A：全对）
     - S2 慢速+2次超时兜底触发（脚本B）
     - S3 中途断网30s重连续课（脚本C）
 30  三人课中同时提交反馈：S1"太多" S2"周三有事" S3"abandon难记"
     → SystemAgent 并发处理3条：S1 调参、S2 排课、S3 Boost
 45  三人下课；SystemAgent 并发排3套下一课（间隔阶梯正确）
 46  admin 查审计：本轮所有 Agent 调用/配置变更/判分记录完整可查
断言:
 ① 三学生 memory_cards/lessons 互不串库（数据隔离）
 ② 三条反馈状态机各自正确收敛 applied
 ③ S2 课程改期成功且与 S2 其他计划无冲突
 ④ S3 abandon 下次课在批次头部
 ⑤ 全程 trace_id 无断裂；课堂事件可完整回放
 ⑥ 无死锁/竞态（-race 通过）
```

### E2E-02「课堂协同拟真：老师 Agent 与学生实时互动」

```
Playwright 双视角（同课堂）:
 - 学生视角: 点击单词→听朗读(Mock TTS 图标动画)→跟读(注入麦克风静音→触发按钮兜底)
   →小测语音作答(ASR Mock 返回脚本答案)
 - 服务端视角(断言): ui_action 序列 = 设计稿顺序；每个学生事件→Agent 决策延迟<1s(Mock)
 - 干扰注入: 学生在判分前狂点按钮(seq 去重)；朗读中点下一词(播放队列不被打断)
断言: 打勾✓动画后词不再出现于本课综合测试；打✗词进入回顾面板
```

### E2E-03「管理员与学生并行操作互不干扰」

```
S1 正在上课(进行中) 时:

### E2E-04「逾期与请假拟真」

```
S1 首课后消失 48h（时间 Mock 快进）:
 cron 巡检→lesson expired→重排次日→通知
 S1 回归登录→看到改期通知→按新时间上课→阶梯未前进
 S2 提前请假"周五有事"(D类)→周五课顺延至周六→两课不冲突
断言: 逾期词 LadderStep 不变；通知中心时序正确
```

### E2E-05「反馈风暴与边界保护」

```
S1 连续提交10条反馈（混合 A/C/D 类+超界请求）:
 - 并发到达 → SystemAgent 串行处理（同学生反馈排队）
 - 超界项全部 need_confirm / escalate，无一越界写配置
 - 月推迟累计≤3 次限制生效
断言: config 终态=合法值；审计完整；学生收到逐条回复
```

### E2E-06「课堂进程故障恢复」

```
S1/S2 各上课至中段 → 服务进程 kill -9 → 重启:
 - 两课堂均自动恢复，学生端重连后续课
 - 已判分题目不重复判；已毕业词不复活
断言: classroom_events 无断档；lesson_state 与事件流一致
```

### E2E-07「异常与边界拟真」（评审补充 TE-03，P0）

```
a) 老师Agent运行时课中崩溃（kill 话术层 goroutine / LLM Provider 挂死）:
   断言: 平台计时器照常触发 phase_timeout，快路径继续推进，课堂不卡死；
         话术降级为模板原文；Agent 恢复后自动接管话术层。
b) 同一学生双标签页同时进入同一课堂:
   断言: 两连接均收广播；作答幂等（一页答题另一页重复提交返回同一判分）。
c) 两学生同时学同一词库（各自独立计划）:
   断言: 批次/记忆卡互不串扰；词库静态数据共享只读。
d) 管理员在学生上课中途下架(archive)该词库:
   断言: 当前课不受影响；下架后不产生新课；学生收到词库下线通知。
e) WS 消息风暴: 学生端 1s 内发送 200 个心跳+事件混合帧:
   断言: 服务端限流丢弃+告警日志，课堂正常推进。
f) 判分与超时竞态: 作答倒计时归零瞬间提交 ASR 结果:
   断言: 先到事件生效、后到丢弃且记 warn，无双重判分。
