## Goal and boundary

Prove that a valid token and active PREFLIGHT transaction bound to lesson A cannot authorize the approved UPDATE trigger to inspect or accept lesson B. The trigger source itself is allowed, so rejection must come from the typed row projection and challenge binding, not from an authorizer shortcut. This is one component negative only; it does not satisfy the guarded-App/listener-factory or full docs/78 matrix gates.
