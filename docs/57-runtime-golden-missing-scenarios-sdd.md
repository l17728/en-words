# Runtime Golden Harness Completion SDD

EEXIST control frames are decoded as a closed protocol: reject duplicate or unknown JSON keys, missing/null required fields, trailing JSON values, wrong field types, and unknown message types; enforce a type-specific semantic schema. Poll retries `EINTR`; `POLLERR` and `POLLNVAL` are fatal descriptor/protocol errors. On Linux SOCK_SEQPACKET, a zero-byte read at peer close cannot be distinguished from a queued zero-length record, so peer closure at a required barrier is fatal rather than `NOT RUN`. Fault-path E2E tests must assert a process-specific bounded cleanup record (`reaped=true`, `cleanup=CLEAN`, `timed_out=false`) as well as the expected failure marker.

The child sends a terminal `DONE` frame with the reserved sequence value `0` after all wrappers finish and the callback trace is durably published; ordinary frames continue to use contiguous positive sequence numbers. The parent accepts normal completion only after this typed terminal frame, then independently waits for and verifies child exit; EOF before `DONE` is a protocol failure. The initial `UNAVAILABLE` path also requires `DONE`, clean exit status, bounded reap, and successful final trace publication before it can be `NOT RUN`.

A zero-length `SOCK_SEQPACKET` record remains malformed even if peer hangup is reported at the same time; inspect `MSG_EOR` before classifying zero-byte peek as EOF. The initial `UNAVAILABLE` path is only `NOT RUN` after child exit code zero, bounded reap, and successful final trace publication.

## Status and boundary

This SDD covers only the two rows in docs/56 that the current candidate generator hard-codes as `NOT RUN`: `VFSFLAGS-SIDECAR-EEXIST-REOPEN` and `PAGER-HOT-ROLLBACK-EXCLUSIVE`. It authorizes test-only Linux/CGo helpers and disposable child processes. It does not implement or register a private production VFS, change SQLite production wiring, or promote host-VFS observations to canonical goldens.

## EEXIST retry scenario

Build a test-only `LD_PRELOAD` syscall interposer from checked-in source using the reported C compiler. The child receives one bounded `SOCK_SEQPACKET` control FD and an exact temporary WAL path. Every control packet is one JSON frame no larger than 4 KiB with `{version, scenario_id, seq, type, target_token, flags, result, errno, qualifying_exclusive_create, symbols_ok}`; sequence numbers increase contiguously by one, `target_token` is SHA-256 of the exact path, and no raw path is sent. `READY`, `UNAVAILABLE`, and syscall-result frames are one-way observations; the parent acknowledges each `EXCLUSIVE_CREATE_OBSERVED` frame using the same sequence number and an allowlisted type (`CONTINUE` or `INJECT_EEXIST`). Parent and child use 10-second monotonic deadlines for each request/ack exchange; the parent also applies a 10-second overall EEXIST protocol deadline. Poll retries `EINTR`; EOF, malformed frames, or timeout disables injection and triggers bounded kill/reap cleanup. The C interposer serializes frame/ack/result exchanges under one mutex, and unresolved `RTLD_NEXT` wrappers or inability to canonicalize the target send `UNAVAILABLE` and fail closed. Path matching resolves the parent directory (`realpath` or `/proc/self/fd/<dirfd>`) and appends the leaf; it never falls back to a raw relative path. `open`/`open64` read the variadic mode only when `O_CREAT` or `O_TMPFILE` requires it and preserve errno; `openat`/`openat64` canonicalize relative paths against `dirfd`. Every exact-path attempt is reported, but the parent authorizes collision creation and the interposer injects only when flags contain `O_CREAT|O_EXCL` and do not represent `O_TMPFILE`; nonqualifying exact-path attempts receive `CONTINUE`. The one-shot injection returns `-1/EEXIST` once, then delegates retry calls and reports each result. READY includes wrapper availability; `UNAVAILABLE` is a capability failure before injection. If the child exits without an exact path or without any qualifying exclusive-create attempt, report `NOT RUN`; wrong target token, qualification mismatch, duplicate/unauthorized `EEXIST`, missing retry, or failed WAL open fails the run. Once an exact-path attempt is reported, malformed frame/ack, EOF, or timeout fails even if injection has not yet occurred; it cannot be reclassified as `NOT RUN`. Only independently captured syscall evidence may attribute a bypass. Failure paths preserve stdout, stderr, raw child trace, protocol outcome, timeout, kill/reap and descriptor-cleanup diagnostics as immutable artifacts.

## Hot rollback scenario

Use a child test process with `journal_mode=DELETE` and `synchronous=FULL`. It receives one inherited `SOCK_SEQPACKET` control FD. The shared 4 KiB JSON frame schema carries `{version, scenario_id, seq, type, handle_token, offset, size, delegate_rc, callback_returned}`; child and parent use strictly increasing sequences and 10-second monotonic deadlines. Send and receive readiness are bounded and retry `EINTR`. The child reports successful delegated journal `xSync` as `JOURNAL_SYNC_OK`; because the tracer wrapper is still waiting at this barrier, `callback_returned=false`. The parent validates and replies `CONTINUE`. After this acknowledgement, the callback wrapper delegates each main-DB xWrite and selects the first result where the exact main-file handle matches, `nBuf>0`, offset is nonnegative, and delegated rc is SQLITE_OK. At the atomic barrier point, the full underlying xWrite has returned SQLITE_OK but the outer tracer xWrite has not returned, so `callback_returned=false`. The child appends the callback event to its raw trace file and `fdatasync`s it; only then does it record durable sequence/reference/hash, send `MAIN_WRITE_DELEGATED_OK`, and block. The parent validates order and handle, confirms journal presence, records old SQL value plus crash-time main DB bytes/hash and journal bytes/hash under immutable artifact references, then sends SIGKILL and waits/reaps. Reopen through the traced host VFS must recover the old committed value. A normally completed child with no qualifying write is `NOT RUN` with partial trace; SQL errors, malformed/EOF protocol, bad acknowledgement, timeout, cleanup failure, missing journal after the write barrier, or unexpected recovered value fail the run and cannot emit a candidate. A deliberate SIGKILL after the validated write barrier is recorded as `killed=true`, `timed_out=false` when reap completes within its bound. `timed_out` is set only when a protocol deadline or bounded wait actually expires. On failure, persist child stdout/stderr, available partial trace and a cleanup manifest containing kill/reap/descriptor errors; never infer cleanup success from a requested kill.

## Acceptance and observability

Both rows retain stable IDs and complete oracle details. A child never started has `started=false`, `execution_status="NOT RUN"`, `cleanup_status="NOT_APPLICABLE"`, and null exit/terminal/output fields; a started child records process outcome, separate stdout/stderr references, hashes/byte counts, timeout/kill/reap, and control-FD closure. Capability missing before start maps to `NOT RUN`; a child that exits normally without a required trigger also maps to `NOT RUN` with partial trace. Once an EEXIST is injected or a hot-write barrier is acknowledged, protocol/SQL failures, timeout, missing journal, or recovery mismatch fail the run and cannot emit a candidate. Add negative tests for wrong target/flags, duplicate injection, wrapper-bypass classification (which requires independent syscall evidence), absent retry, malformed/EOF/deadline protocol for each scenario, barrier ordering, wrong handle/offset, durable trace before acknowledgement, crash-time evidence hashes, timeout/kill/reap, and existing-artifact preservation. Run focused cases, tagged package, `-race`, `vet`, formatter, candidate artifact audit, and exact-hash code/design review on Linux. Any unsupported syscall/toolchain path is explicitly `NOT RUN` with the measured missing capability.
