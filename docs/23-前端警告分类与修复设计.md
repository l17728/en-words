## 2. 开课时间门修复规格

当前Dashboard只有加载课表/反馈等事件触发render，页面静置不会因为真实时间流逝重新计算openNow。拟增加显式时钟状态：lazy初始化Date.now；effect每秒更新一次，页面重新获得focus/visibility可立即更新；cleanup清timer及监听器。render只读取时钟状态，纯函数`isLessonOpen(openAt, now)`对合法过去/相等时间开放、未来/非法时间关闭。最多1秒展示误差，后台接口继续独立验证开课时间；不修改排课、服务器时钟或提前进入权限。

提取最小`watchScheduleClock`订阅器承载timer/focus/visibility与cleanup，可注入时钟/定时器/EventTarget供Node测试。浏览器hook仅订阅并setState，避免在effect中同步setState；不引入全局可变会话时钟或额外网络轮询。

### 6.1 协议与草稿合同

新增页面局部答题/跟读就绪门，identity为有效context的(epoch,turn)，附phase=wait_answer或repeating。同步ref是发送/采集授权事实源，React state仅用于输入disabled和effect依赖。epoch/turn不含用户凭据；会话仍由既有userId+token守卫。

- 只有通过现有seq/epoch校验的业务show_quiz_item或start_repeat建立对应ready；REST enter快照、state_snapshot和WS open只呈现状态，绝不自行授权回答/录音。
- 新题identity与上次草稿identity不同才清稿；同identity重复show_quiz_item（即使seq更新）不清稿。断线保留当前草稿但禁用，只有同identity业务重发才恢复编辑；重连后新epoch视为新题清稿，不把旧草稿当新题答案。离开答题/暂停可保留不可编辑草稿，下一新题清稿；换账号/课程直接清除页面私有草稿。
- 相位离开对应ready、context改变、paused、session_timeout、classroom_error、lesson_summary、WS close、鉴权失败及组件卸载立即使ready失效并stopListening。phase_changed进入wait_answer/repeating不建立ready。同步失效避免React effect尚未cleanup时迟到回调发送。
- typed answer_submitted统一入口必须同时满足在线ref、当前会话、有效ready=当前context且phase=wait_answer、text.trim非空。按钮/回车共用此门，未就绪显示“正在恢复题目，请稍候”，输入禁用；空白按钮禁用。业务回答不经断线REST兜底绕门，其它既有控制/反馈降级合同不变。

### 6.2 两条自动采集链同门

native SpeechRecognition和本地recordLocal两条effect依赖完整ready identity，不能只依赖phase/词面（同词新turn也必须重新采集）。采集开始冻结ready context/phase与token；每次start/onstart/onresult/onend重启，以及本地录音前与await后，都验证同一ready仍有效且在线。过期回调不读取新context借用权限。采集退出立即停止/abort；start_repeat合法建立repeating门，保留跟读及其语音命令能力。sendVoice答题/跟读入口再次校验capture context；独立反馈对话框不依赖课堂麦克风就绪门。
