# 08 E2E 测试方案（Playwright 无头模式）

> 项目代号：en-words ｜ 版本：v0.1 ｜ 状态：待评审
> 决策（用户定案 2026-08-23）：**E2E 一律使用 Playwright 无头模式（headless Chromium）执行**。
> 上游：[03-测试用例.md](03-测试用例.md) §4 场景定义；本方案给出可执行规格（工具链/工程结构/用例映射/覆盖率门）。

---

## 1. 工具链与运行方式

| 项 | 决策 |
|---|---|
| 运行器 | Playwright Test（`@playwright/test`） |
| 浏览器 | **Chromium headless**（CI 与本地一致；NF-08 的 Edge/Chrome 双核抽检用 `--headed` 手动触发，不入 CI 门） |
| 被测系统 | 真实单二进制服务：`enwords-server.exe`（内存 SQLite + 全 Mock Provider），webServer 钩子自动拉起 |
| 账号 | globalSetup 播种：admin×1 + 学生 S1/S2/S3 + 双 Agent 服务号；词库播种 g7(691)/g9(531) 两库 |
| 时钟 | 服务暴露 `__test__/advance_clock`（仅测试构建启用）——E2E-04 时间快进用 |
| 语音 | Mock Provider 脚本号驱动（页面 `__TEST__.mockASR('苹果')` 注入；麦克风权限 stub 为 allow 但不采真音频） |
| 截图/trace | 失败自动截图 + trace.zip（`trace: 'retain-on-failure'`） |

`playwright.config.ts` 关键项：

```ts
export default defineConfig({
  testDir: 'e2e', timeout: 120_000, retries: 0, workers: 1,  // 课堂时序敏感: 串行
  use: { headless: true, baseURL: 'http://127.0.0.1:18080',
         permissions: ['microphone'],
         viewport: { width: 1280, height: 800 } },
  webServer: { command: 'dist/enwords-server.exe -port 18080 -testmode',
               url: 'http://127.0.0.1:18080/api/health', reuseExistingServer: false },
  expect: { timeout: 10_000 },
});
```

## 4. 覆盖率要求（E2E 门）

E2E 覆盖率定义两层，均须达标：

**P1 页面/路由覆盖 =100%**（`web/e2e/coverage` 用 CDP 收集 `Page.navigate` 事件自动核对清单）：

```
/login /books /placement/:bookId /dashboard /classroom/:lessonId /stats
/admin/wordbooks /admin/wordbooks/:id /admin/import /admin/users
/admin/config /admin/audit /admin/todos
```

**P2 关键用户旅程覆盖（每个 FR 域至少 1 条绿路径）**：

| FR 域 | 旅程 | spec |
|---|---|---|
| A 账号 | 登录/改密/被踢 | 01/06 |
| B 词库 | 导入→预览修正→发布→下架 | 06 |
| C 摸底 | 全流程+断点续做 | 01 |
| D 课堂 | 教学/小测/综合/期末/RETEACH/续课 | 02/03 |
| E 记录 | stats 页数字与课堂结果一致 | 02 |
| F 排课 | 首课/改期/逾期/计划视图 | 04 |
| G 反馈 | A~D 意图闭环+超界确认 | 05 |
| I Agent | Mock 双 Agent 决策可见（话术气泡/通知） | 02/05 |

**G 门挂钩**：`npm run e2e` 退出码 0 = E2E 门通过；输出 JUnit 报告归档 `web/e2e/report/`。

## 5. 准入与频率

- 前端骨架就绪后立即建立 `fixtures.ts` + 冒烟（登录→dashboard），随后按 spec 顺序补全；
- 每次提交本地必跑（<10min）；真 Omni 接入后加 nightly `--project=real-omni`（L3 层，05 §V-8）。

## 7. 2026-10-13闭环与朗读设置专项

在 `web/` 下依次运行（专用端口与隔离数据库，不能同时运行三个配置）：

```powershell
npx playwright test --config=playwright.closure.config.ts
npx playwright test --config=playwright.firstuse.config.ts
npx playwright test --config=playwright.playback.config.ts
```

closure覆盖双学生隔离、反馈、跨通道重放、统计故障恢复、个人设置及暂停恢复协议；firstuse覆盖首启到课报/统计/下一课的默认3＋1流程；playback复用完整旅程验证2＋2及不同间隔、当前课冻结和下一课1＋1。具体增量用例见03第8节，实际报告见14。

使用构建后的Vite preview和无头Chromium。媒体mock记录开始/结束时间以检验串行播放及最小停顿；暂停浏览器测试明确注入WS协议，真实会话超时由Go FakeClock验证。以上专项不能替代历史全套旅程、真实音频质量或race验收。当前package.json没有 `e2e` script，使用上列配置命令，不沿用第4节旧的 `npm run e2e` 命令。
