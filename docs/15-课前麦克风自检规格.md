# 课前麦克风自检规格

## 目标

学生进入课堂前，可以用一句固定英文短句验证浏览器权限、麦克风采集、录音编码和本地 ASR 是否可用。

## 流程

1. 课程表的下一节课提供“测试麦克风”入口，不改变课程开放时间。
2. 自检页显示并朗读提示句 `This is a cat.`，学生点击“开始测试”后录音最多 4 秒。
3. 复用 `recordLocal(lessonId, "en")` 上传到现有转写接口；成功条件为返回非空文本且包含 `cat`。
4. 通过后显示识别文本和“进入课堂”按钮；失败时保留“重试”，并提供返回课程表路径。
5. 页面卸载、重试或超时必须停止录音轨道；自检不推进课堂状态、不写学习结果。

## 可观测性与验收

页面记录 `mic_check_started`、`mic_check_passed`、`mic_check_failed` 事件（不记录音频内容）。E2E 覆盖通过、ASR 失败、麦克风拒绝和返回路径；前端构建必须通过。
