# 朗读缓存与模型配置评审记录

## 评审结论

架构、后端、前端、测试和安全检查均已完成。缓存键包含模型、服务和规则版本，避免旧音频污染；数据库只保存元数据，生成文件目录已忽略；管理员应用配置经过能力校验并写审计日志；无模型服务时保留文字输入降级。

## 已处理问题

1. 原先 `vl/asr/tts/tts-en` 直接散落在客户端请求中，改为可持久化 profile，并保留同名默认方案兼容现有部署。
2. 并发合成可能重复请求模型，增加按缓存键的锁和临时文件原子替换。
3. 管理员只能触发合成，无法判断规则和缓存状态；词条查询现在返回朗读文本、发音变体和中英文缓存状态。
