## 2. 隔离与运行器

公共配置固定loopback，默认非开发端口，允许显式E2E_WEB_PORT/E2E_API_PORT；拒绝8080/5173以及非法端口。所有API请求通过当前baseURL的相对/api路径。每组独立`.test-artifacts/<run>/test.db`，reuseExistingServer=false，绝不删除或复用开发数据。

默认配置负责迁移后的历史组；feedback/closure/首启两组保留独立数据库。新增恢复配置及顺序全量入口，统一headless Chromium、JSON报告、失败trace/截图、后端结构化日志；任意组失败则总退出非零，报告列全量实际执行数和跳过数。测试原文/合成音频均是夹具，不读密钥，不联系云模型。

重启用例由Node测试fixture直接启动预构建Go二进制，持有ChildProcess，不通过go run或全机名称查杀。仅关闭自己启动的进程，等待退出和监听停止后，使用相同DB重新启动；每次重启记录PID、时间和ready结果。配置不增加产品故障端点。测试未结束而进程异常退出立即失败并附服务日志，不能吞掉错误继续断言页面旧状态。

## 3. 网络与重连实现合同（对齐18）

ClassroomWS每次实际建连前通过认证enter刷新ticket，取消/退出/换token的旧结果不得建连。socket关闭或建连失败通知UI并退避，401/403/归属丢失终止并走现有安全退出；正常网络故障保留重连。所有计时器与在途ticket请求受实例关闭和连接代次保护。

onClose取消当前TTS、识别和录音，将旧异步完成标为无效；停止录音不能触发旧正文提交。恢复依赖服务端新turn业务帧，enter/snapshot只更新显示，不驱动朗读；服务端恢复帧必须推进seq或换epoch，不能被客户端旧seq过滤。未确认段可重播，已确认段不得回退；judging重启回同题wait_answer，旧答案不自动重发、不记错。

只修改`ws/client.ts`与Classroom重连生命周期，媒体编码/供应商实现由主代理负责。两方变更按区块协调，测试配置与e2e目录由浏览器代理维护。

### G09 播放失败不可伪装成功（实施前补充）

## REC09 快照破损与临时连接错误（主审批准后实施）

真实课堂先持久化，测试仅停止自有进程后修改隔离 SQLite 的 runtime_records snapshot/ID，再真实重启。非法 JSON 应拒绝 enter（不误报403），界面展示临时恢复失败与返回入口；日志 snapshot_failed/module=store/reason=read_failed/trace_id=lesson-ID，不输出故障正文。合法 JSON 但非法状态另锁 classroom/invalid_snapshot。

WS onError 显式传 retryable 布尔：非认证错误保持1–60秒退避且提示“课堂连接暂未恢复，请重试或返回课程表。”，Tag仍显示重连中；401/403/404终止重试并显示连接已停止。onOpen清临时提示。Node独立状态机测试先红后绿，验证临时错误提示/再次authorize/成功open与终止错误零重试；禁止把存储失败转成403掩盖分类。
