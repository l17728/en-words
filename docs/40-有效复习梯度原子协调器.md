# 有效复习梯度原子协调器

状态：实现、正式工作树验收及本地提交已完成。有效值作用域、事务/回滚、管理员 UI、重启排课与多学生冻结均已覆盖；本地测试通过和提交证据见本文件末尾。设计和评审证据见 `review/ladder-effective-scope-gap-spec-20261016.md`、`review/ladder-atomic-coordinator-design-20261016.md` 及对应 review JSON。

## 目的与范围

修复梯度设置只处理内存仓储、学生覆盖误伤其他学生、删除覆盖不协调、持久化失败留下部分学习进度等一致性缺口。梯度和 `goalMode` 先按既有优先级计算事务前后学生实际生效值；只有有效梯度改变的学生进入裁剪集合。扩长不提升步骤；本功能不重排 `NextDueAt`，不更改复习间隔策略，也不开放 Pilot 或 Agent 敏感配置能力。

## API 与行为合同

- `GET /api/v1/config/effective?studentId=<id>` 只读返回该学生有效配置；缺省 ID 使用全局视图。以下四个 method/path 组合均要求 Admin：两个 GET、`POST /api/v1/config/set` 和 `DELETE /api/v1/config/override`。无效目标拒绝，真实读取失败不得静默回退到缓存。`GET /api/v1/config` 保留管理员全局配置视图。
- `POST /api/v1/config/set` 接受 `scope`、`studentId`（学生范围必需）、`key`、非 null `value` 和 `reason`；`DELETE /api/v1/config/override` 删除学生覆盖并回落继承值。顶层重复、大小写别名、未知、null 字段以及超过 8192 字节的配置 JSON 在绑定前拒绝；具体配置值另按已支持类型和范围进行规范化校验，不提供通用递归 JSON Schema 校验。
- 对受影响学生，只更新 `ladder_step > len(effectiveLadder)-1` 的卡；学生范围覆盖、非步骤字段、卡状态和到期时间不得被误改。目标授权及所有保留范围在首次写入前完成预检。
- 持久仓储先取得 SQLite writer，再在同一原子事务内读取有效配置/范围、写配置和 revision、裁剪卡并写审计；取消、存储错误或提交失败整体回滚。内存实现通过三仓储工作副本协调发布；不支持原子事务的混合后端明确拒绝。
- 写入成功响应使用线上 JSON 字段 `committed`、`changed_cards`、`affected_students`、`noop` 和 `refresh_pending`。配置已提交但缓存重载失败时 `committed=true`、`refresh_pending=true`；新读取仍以持久层为准，不能重放写操作。Effective 响应包含 `student_id`，以及 `goalMode`、`ladder` 字段；各字段说明 `effective` 值、`source`、覆盖存在性/值/回落值和 `revision: {global, student}`。梯度由默认模式推导时包含 `derived_from`、`goal_mode` 来源信息。

## 并发与课堂冻结

配置协调与排课/结算使用同一写序列。完成中的 Room 保留进入课堂时的配置快照；新建课程读取提交后的有效配置。迟到或失败的配置响应不能被前端误认为未提交，界面在状态不明时锁定重复写入，明确对账后才解锁。正在上课的其他学生不应因管理员调整另一个学生或全局默认而暂停或变更其 Room。

## 定位日志

每次变化记录 `config_mutation_started`，并以 `config_mutation_committed`、`config_mutation_rolled_back` 或 `config_mutation_refresh_pending` 之一结束。结构化字段包括 trace、操作、键、scope、适用 student ID、受影响学生数、变更卡数、事务结果和固定错误码。日志、审计摘要不得包含自由格式原因、配置原文、SQL 或学生答案正文。

## 回归与验收

Go 回归覆盖全局/学生梯度和 goalMode 继承矩阵、删除回落、无卡保留范围、内存/SQLite、双连接并发、配置/卡/revision/审计回滚、COMMIT 故障、读刷新失败和严格 JSON 边界。Playwright 真实 UI 旅程覆盖管理员修改/恢复、持久重启后 A 学生使用新梯度排课、并发 B 学生课堂与旧 Room 快照保持不变，以及故障触发器的 finally 清理。历史隔离候选证据保存在 `.test-tools/ladder-implementation-20261016/_baseline/`；本次正式工作树验收另见下方。
