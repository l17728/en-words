# 课堂双工确认与原子决策评审记录

## 开发前结论
架构评审通过：先接通 WS 真实旅程，再迁移课堂状态转换到 SQLite 事务。确认前不判分，REST 文字路径保留，默认关闭双工影子能力。

## 风险与约束
当前 Room 内存状态与收据仍分离；在原子提交改造完成前，不宣称事务级幂等。测试必须区分协议可用、课堂推进和持久化恢复三层证据。

- 平台 harness 增加确定性 ASR 响应和空请求保护。
