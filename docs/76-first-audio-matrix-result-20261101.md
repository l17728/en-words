# 首音课堂性能矩阵结果（2026-11-01）

## 范围与结论

测试采用隔离 SQLite backend、真实 `api.App`、冻结的私有前端 bundle 和 Playwright 无头浏览器，完成 30 次冷样本、1 次不计时热身和 100 次热样本。130 次计时尝试全部成功；失败、超时、未完成和未尝试均为 0。性能门**未通过**：首个 `play_tts` 帧的 p95 高于 2000 ms。

| 指标 | 冷（n=30） | 热（n=100） |
|---|---:|---:|
| 首播放帧 p50 | 1802.2 ms | 1732.0 ms |
| 首播放帧 p95 | 2172.1 ms | 2152.9 ms |
| 首播放帧 p99 | 2242.8 ms | 2200.9 ms |
| 首播放帧最大值 | 2242.8 ms | 2220.6 ms |
| `show_word` 呈现 p95 | 610.9 ms | 487.9 ms |
| mock player `onstart` 相对播放帧 p95 | 3.6 ms | 3.5 ms |

## 诊断与后续

浏览器播放器约在收到播放帧 3.5 ms 后启动，主要延迟发生在播放帧发送前。原课堂等待为 800 ms，状态机由 1 秒 tick 驱动。经评审的 [首音提前量 SDD](75-first-audio-lead-setting-sdd.md) 将其改为可设置值，默认 250 ms、范围 100–2000 ms；旧快照仍恢复为 800 ms。实现后的完整矩阵尚待重跑，不能据此称性能门通过。

该矩阵只验证合成播放器时间戳，不证明真实扬声器起音、语音质量、回声抑制或真人课堂可用性。隔离课堂的真人语音、外放回声、键盘声和网络故障试点仍为独立验收门。
