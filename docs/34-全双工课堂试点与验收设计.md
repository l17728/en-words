## 2. 用户体验与权限边界

1. 试点设置默认关闭。明确显示当前模式：全双工试点、按住说话/原语音、文字；切模式不重置课程或成绩。首次由用户动作授权麦克风并解锁播放，始终有可见开麦状态和关闭入口。
2. 老师字幕仍显示**当前实际发声的段文本**；网络预取/模型生成不是发声。插话停播即清老师活动字幕，历史字幕如需保留单独标“已中断”，不能继续显示“正在朗读”。
3. 学生区域分“识别中（可变化）”draft、“转写定稿，待确认”final及“需确认”needs_confirmation；只有收到持久decision.committed才显示“已提交”。ASR final不是教学提交。draft不覆盖手打未提交正文，不入成绩/反馈/长期记忆；快慢轨首版仅保守规范化后exact match可自动进入确认屏障；其他差异一律需确认，不消费机会。规范化仅Unicode NFC、大小写、首尾/重复空白及单个终末中英文句号（问号、感叹号、省略号、连续多个句号保留），不删除内部标点、不改数字/否定词、不作同义替换；Unicode兼容折叠不默认启用。意义、否定、数量或控制意图冲突不能被相似度或慢轨优先绕过。用户确认所说文字仍须经Judge/Agent，不等于自评正确；提交后纠正通过明确新输入，不暗改已判分事实。读屏只低频提示阶段与最终文本，不逐帧播草稿。
4. 老师说话期间的学生声音首先是插话意图，不等于当前测验答案。诸如“不会”“跳过”“等一下”“再读一次”、中英混说，由当前相位下Agent/已有命令合同处理。明确不会与空白、静音、ASR失败严格分开。
5. 键盘/触摸停止老师、关闭麦克风和文字提交始终可用；每轮最多一个业务输入被接受。手动文字先提交后，迟到语音final必须被同一输入门拒绝，反向亦然。窄屏老师字幕/学生识别文本自然换行，不能覆盖答案输入和退出按钮。
6. 断网、权限拒绝、设备拔出或模型不可用时清楚说明失败阶段，保留手打草稿，提供文字继续与显式重试。绝不自动启用未配置云服务，也不把被取消语音自动重放到新题。

## 3. 采集与端点SDD提案

### 3.1 设备能力证据

采集前记`getSupportedConstraints()`支持声明；获轨后采样`getCapabilities()`（存在时）和`getSettings()`；申请的AEC/NS/AGC与**实际设置分别记录**。设备切换、恢复采集后重新读取。字段缺失记`unknown`，false记`disabled`，不能用请求值补全为true。设备ID、label不进常规日志；验收清单使用匿名设备编号。

建议初始申请`echoCancellation/noiseSuppression/autoGainControl: {ideal:true}`；对不支持/未知设备不硬拒文字课，但不显示“已通过外放双工”。AGC开启也可能改变弱短词/削顶，应与关闭条件对照，不能仅凭true判合格。实际settings只说明浏览器轨道配置，不能证明声学效果。[W3C Media Capture and Streams](https://www.w3.org/TR/mediacapture-streams/#constrainable-properties)给出约束/设置模型。

试点浏览器矩阵先限定实测Chrome/Edge版本、OS、输入输出设备和权限状态；HTTPS或满足浏览器安全上下文要求的本机环境才进入麦克风预检。手机/蓝牙/远程设备不能因桌面通过而继承结论；若首期不支持须在设置明示。此次不更改宿主系统/浏览器全局音频设置。

### 3.2 媒体路径与背压

候选路径：一个受会话生命周期管理的mic track→浏览器音频处理→连续PCM采集器→短环形预录缓冲→VAD/带序号媒体帧→鉴权媒体网关→ASR草稿/终稿。AudioWorklet或WebRTC上行选型由33冻结；不能把任意MediaRecorder容器切片当独立可解码WAV。实际采样率、声道与重采样转换必须显式协商并记录。

提案参数供预实验：与32/33统一候选：20ms音频帧、80ms发送批次、300ms预录、200ms尾留、终点静音600ms；长句允许停顿但每个新stream utterance最长15s，达到硬上限则标未完整提交并提示重说，不静默裁切判分。原legacy录音仍为4s，不因试点参数改变。初始speech candidate观察窗100ms，但这不是最小可接受发声长度：环形缓冲必须保留更短的起音及尾音，不得因低于100ms直接丢弃“猫、狗、go、a”。短候选的endpoint/不确定处理仍须显式输出，不能静默过滤。参数必须先冻结后评价，失败后改参数须新版本及完整对照，不调到单个样本刚好通过。

未ACK音频缓冲建议最多2秒；排队溢出、序号缺口、采样不连续时标该utterance不完整并请求重说/文字，不能拼接成貌似完整答案。网络断开立即停止上传和本地播放，清当前utterance，重连新stream generation，旧缓存不跨新身份/课堂发送。生产不默认持久录音；只在明确验收采集期间保存隔离素材。

## 4. 插话、输出取消和业务一致性

本地近端speech-start立即执行**可逆媒体停播**，不先duck等待确认，不等待ASR/服务端。建议证据同时包括VAD onset与AEC后的近端候选；不能只用远端播放能量或“转写包含目标词”认定学生讲话。误触发不计答题失败，老师Agent决定是否从被中断段开头恢复；实际已完成段不重复，不从无法证实的字级位置续播。确认前接话仅固定中性模板，禁止自由模型评价或泄露答案。VAD阈值/回声相关判别属媒体策略，不得硬编码教学推进。

一次插话按以下次序：同步失效output generation/字幕lease→撤销待播队列和预取订阅→停止Audio/原生TTS/流式音频输出→发带ID的取消控制→继续同utterance采集。已进扬声器缓冲的残声需要物理测量，`pause()`返回不代表人耳已静音。

| 对象 | 拟冻结身份/规则 |
|---|---|
| 输入 | session generation、lesson、epoch、稳定input_revision（题目/机会/显式撤答/授权版本）、stream generation、utterance ID、chunk seq；turn仅为起始传输证据，不以judging/preview引起的turn变化撤销合法final。服务端decision_id是持久提交身份，event_id仅帧关联。 |
| 输出 | response ID、output generation、segment ID/seq；音频chunk和字幕同归属。迟到playing/end/chunk全拒旧generation。 |
| draft/final | draft revision递增只更新当前utterance；final仅转写定稿，decision.committed才一次业务接受；final后同utterance旧草稿拒绝，冲突final进入澄清且不写成绩。 |
| 取消 | cancel ID及目标output generation，重复取消幂等；本地先停、服务端确认后收敛。取消不是`tts_finished`，旧成功ACK不推进下一段。 |
| 提交恢复 | 超时表示送达未知；以原input ID查询/恢复，不新造ID重判。同utterance跨重连只能查询已接受状态，不能将旧音频重播当新回答。 |

朗读相位的插话输入与wait_answer答题授权必须分开：允许检测近端声音和请求取消，但只有服务端接受当前逻辑input_revision/题目机会的确认输入才可能交给Agent。新epoch或新逻辑题目/机会先失效旧采集和pending；单纯preview/judging展示相位不撤销合法在途确认。暂停、结课、退出、换号、换课释放轨道、队列、定时器和订阅。旧异步ASR/LLM/TTS返回不得重新开麦、显示新字幕、触发判分、改成绩或重启旧播放。

控制消息必须独立于慢模型工作队列，有界排队并对满队列明确拒绝；候选媒体通道不能使已有心跳/退出等待L2。传输具体消息名、幂等保存/ACK顺序及事务提交点以33为准；本文不是已上线协议。WebRTC规范仅定义传输能力，不能替代本项目的业务幂等合同。[W3C WebRTC](https://www.w3.org/TR/webrtc/)。

### 5.1 音源、硬件和盲评

- 先冻结至少300条独立人工确认录音（建议至少6名自愿发声者，每类分层；首期可成年用户，不将其外推为儿童验收）：中文单字/短词、英文孤立词、完整释义、中英混说、不会/跳过/重复请求、否定/犹豫/停顿；必须分层包含“不会”、否定不会、明确跳过、否定/引用跳过、句头句尾短词与老师尾音重叠，不能只以整体WER覆盖命令语义。发音/文字gold/允许变体/语言分词在首次模型调用前签收并SHA冻结。
- 原已知“猫”不清音源与B完整句保持历史独立；不得换音源或改gold把旧失败重算通过。TTS模型生成输入只能是补充合成轨，不能和真人样本混为一个质量分母。
- 每套物理设备固定麦克风/扬声器编号、距离（建议0.5/1m）、系统音量、房间/背景噪声条件，耳机基线与外放分开；记录设备、浏览器/OS/模型/参数哈希。最好用独立参考录音机/声卡第二通道同时记录近端起声与外放实际停声，人工校准时钟，不拿浏览器时间戳直接跨机相减。
- 回声场景包括老师独说（学生静音）、学生独说、双讲学生比老师弱、键盘/风扇/背景人声、老师外放含“不会/跳过”、老师尾音时学生短词、耳机拔出改扬声器。固定SNR条件必须说明测量方法，不能把系统音量百分比当dB。
- 原始录音/参考声道隔离存储，列用途、授权及保留期限；常规日志/提交不含音频、正文、token、设备原始ID。可提交脱敏统计、匿名设备矩阵、SHA与失败分类；评审者按事先名单盲听，争议先标不确定，不看模型输出改标签。
