# 跳过意图短语最小规格与 SDD

## 问题和范围

独立合成语音评估中，用户原话“我想跳过”是显式意图，但 `voicecmd.DefaultTable` 仅接受“跳过”等短语。即使 ASR 逐字正确，课堂也不会执行跳过。修复增加完整短语“我想跳过”作为 `CmdSkip` 别名，并同步加入 `api/ingress.go` 普通文字答案的显式跳过短语表。两处沿用现有 `normalizeControl`、相位白名单、事件幂等及 `quiz_skipped` 日志；REST、WS voice_text、跟读和普通答题的业务语义一致。

## 安全边界

“我想挑过”等同音误转写不得直接跳过；“我不想跳过”“我想跳过吗”“我想跳过这个词然后退出”、引用句和超长输入不得命中。语音转写不确定时保留现有文字输入“跳过”路径。该修复不提高 ASR 9/12 的准确率，也不替代真人声学验收。

REST/WS 普通答案入口将原文传给 Room；Room 先对原文判定完整指令，再对后续答案执行既有 `sanitizeText`。否则 `我想跳过<不是命令>` 会被去标签后误判为跳过。普通判分的清洗边界不变。

入口在取得 Room 锁前拒绝超过 2048 字节的事件文本；暂停课堂不记录未执行的 `quiz_skipped`。超长、暂停和附加标签均需 Go 与浏览器负例。

## 验收

Go：解析器正负例；真实 Room 的跟读、答题短语跳过均恰好推进一次，重复事件不再推进；答题日志保留 `reason=explicit_skip` 且不写原文。Playwright：学生在跟读输入框、答题输入框及 `/voice` 转写入口提交“我想跳过”；负例不推进，两个学生的课互不影响。回归覆盖现有 `repeat-contract.spec.ts` 与相关 Go 测试。
