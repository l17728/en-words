## 1. 设计原则

1. **一屏一事**：每屏只有一个主任务焦点（课堂页尤其如此），装饰让位于内容。
2. **零学习成本**：学生首次进入不需教程——按钮即所见（"点单词→听→跟读→答"），所有操作 ≤2 次点击可达。
3. **节奏可见**：课堂进度永远可见（组进度条/倒计时环），学生不焦虑"还有多久"。
4. **鼓励而非评判**：错误反馈用暖色+引导语，绝无红色警告轰炸；正确用轻量庆祝。
5. **家长可信赖**：管理端克制、数据准确、术语专业——家长看到的是"教学工具"不是"游戏"。
6. **静音可学**：所有语音皆有视觉等价物（字幕/动画/文字兜底框），公共场合静音也能完成学习。

## 2. 双端定位差异化

### 2.0 叮当老师人设（产品名定案 2026-08-23）

- **形象**：橘色小猫老师（开场插画 `design/splash-1280x720.png`，卡通画风 8/10 评审通过）——大眼睛/紫围巾/金铃铛/单词绘本
- **自称**：课堂话术自称"叮当老师"（OP 系列开场白），通知落款"叮当words"
- **配色**：老师专属紫 `#8B5CF6`（气泡边框/头像底）与青绿主色形成"师生双色"体系
- **声音**：默认 Omni 音色 Tina；可通过语音克隆（docs/05 §4.6）上传 10~20s 音频定制"专属叮当老师"（如家长/孩子喜欢的声音），配置页选择"预置音色 ∪ 克隆音色"
- **性格**：温和陪伴者（§9 语调），稍快节奏、鼓励型、绝不评判式批评

| 维度 | 学生端（/books /placement /dashboard /classroom /stats） | 管理端（/admin/*） |
|---|---|---|
| 气质 | 清爽活泼、留白多、圆角大 | 专业紧凑、信息密度高 |
| 主色 | 青绿 Teal（成长感、护眼） | 靛蓝 Indigo（工具感） |
| 圆角 | 12px（卡片）/ 999px（按钮胶囊） | 6px |
| 插画/动效 | 轻量几何插画 + 教学动效 | 无装饰动效 |
| 文案 | 口语化、鼓励语气 | 中性、精确 |

## 5. 排版与字体

| 用途 | 规格 | 说明 |
|---|---|---|
| 课堂单词（英文） | **bold 96px** / 行高 1.1 / letter-spacing 0.01em | 单词卡主角；使用 `Georgia/Times` 系衬线以提高单词辨识度（可选 `font-feature: "ss01"`） |
| 单词音标 | 20px gray-600 | 单词下方 |
| 中文释义 | semibold 40px | 翻面/RETEACH 时展示 |
| 老师气泡话术 | 17px / 行高 1.7 | 最大宽度 560px，自动换行，≤60 字 |
| 页面主标题 | semibold 24px | |
| 正文/表单 | 16px / 行高 1.6 | |
| 辅助说明 | 13px gray-600 | |
| 数字（倒计时/进度） | tabular-nums | `font-variant-numeric: tabular-nums` 防跳动 |

中英混排：中文与英文/数字之间自动加 0.25em 间距；英文单词永不换行（`word-break: keep-all` + 连字符断词仅词组词库）。

| QUIZ_WAIT | 仅英文题目 | 自动开麦（zh-CN，说中文意思）+ 文本输入兜底 + 倒计时环 |

| JUDGE 错误 | ✗ 抖动(红) 200ms → 显中文释义 | 自动进 RETEACH |
| REVIEW | 中文大字+自动播英文 | [下一个] |

## 7. 课堂交互细节

1. **倒计时环**：SVG 环形进度（答题 20s/跟读 10s），剩 5s 变 warning 色并脉冲；到点不弹窗——自动判"没想起来"并温和推进（D12 不断顿原则）。
2. **TTS 播放指示**：`🔊 ●●○` 遍数点亮式，非跳动数字；被跳过的遍显示空心叉（tts_skipped 可视化）。
3. **判分动画**：✓ = scale 0.8→1.1→1 弹跳 300ms + 轻音效(默认关)；✗ = 水平抖动 200ms + 释义滑入。全屏禁止使用红色闪/警报音。
4. **老师气泡**：头像+紫边气泡，新话术到来时轻微上滑入场；同一时间最多 1 条（新话术替换旧的，不堆叠滚动）。
5. **跟读监听指示**：🎙 标签 + "大声读出这个词～"文案（自动开麦 en-US）——给学生"老师在听"的确定感；老师听读判读通过自动下一词（2026-08-25 定案，无按钮；无麦克风权限时超时自动计为完成兜底）。
6. **断线黄条**：顶部 `网络开小差了，重连中…(第 n 次)`，课堂内容保持最后状态灰化冻结；恢复后绿条 1.5s 自动消失。
7. **误触防护**：TTS 播放期操作区整体 `pointer-events:none`；[退出课堂] 需 Modal 二次确认并注明"进度已保存，随时可以回来"。
8. **庆祝克制**：组全对/综合零失误 = 彩纸粒子 800ms（仅这两种场景）；单词级正确只用 ✓ 动画，防疲劳。

## 8. 状态与反馈

| 状态 | 表现 | 时长 |
|---|---|---|
| 加载(页面) | 骨架屏（词芯片形状占位），非转圈 | ≤1s |
| 加载(按钮) | 按钮 loading + 文案不变 | - |
| 空状态 | 几何插画(120px)+一句话+主行动按钮 | - |
| 提交成功 | Toast(顶部居中, primary 边) | 2s |
| 判分中 | 倒计时环冻结+"老师正在听…" | ≤5s |
| 错误(可重试) | 内联提示条(warning) + [重试] | 常驻 |
| 错误(系统) | 结果页式 Modal，文案无术语（"出了点小问题，代码 Err-102 已记下"） | 手动关 |

**禁止**：全屏 loading 超过 1.5s；连续 Toast 叠加超过 2 条；未经学生操作触发的声音（自动播放策略也要求如此）。

## 9. 文案语调规范（亲子）

基调：**温和的陪伴者**——像一位耐心的家教老师，不评判、不催促、具体表扬。

| 场景 | ❌ 避免 | ✅ 推荐 |
|---|---|---|
| 摸底引导 | 请完成词汇量测试 | 走一遍词库，把已经认识的点亮，剩下的交给我 |
| 答错 | 回答错误！ | 这个词咱们再认识一遍，很正常～ |
| 超时 | 时间到，0 分 | 没想起来也没关系，看一下提示 |
| 完成 | 任务完成 | 今天的 60 个词全部搞定，比你昨天快了 3 分钟！ |
| 退出挽留 | 确定退出？进度将丢失 | 进度已经存好啦，明天 19:00 我们继续？ |

数字反馈规则：优先"具体进步"（快了 3 分钟/比昨天多对 5 个）而非冷百分比；负向数据不显示给学生（答错次数只给老师 Agent 和家长端）。

## 10. 可访问性基线

- 文本对比度 ≥ 4.5:1（gray-600 on gray-50 = 5.5:1 已达标）；大字号单词 ≥ 3:1
- 全部可交互元素焦点态可见（focus-ring 统一），支持 Tab 完整走查
- 按钮实触区 ≥ 44×44px；相邻按钮间距 ≥ 8px
- 动效遵循 `prefers-reduced-motion: reduce` → 关闭粒子/弹跳，保留透明度过渡
- 声音均有视觉等价物（§1 原则 6）；麦克风不可用自动切文本兜底并提示
- 色盲安全：✓/✗ 除颜色外加形状差异（勾/叉图标本身）
