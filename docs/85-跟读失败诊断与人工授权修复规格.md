# 跟读失败诊断与人工授权修复规格

## 目标

将课堂跟读失败统一沉淀为可追踪事件，由老师 Agent 分析原因并提出建议；管理员通过明确的人类评价授权修复。课堂快路径不等待分析，分析结果不直接改变课堂状态。

## 范围

- 覆盖 ASR 超时、音频无效、转写未匹配、教材缩写、同音词和连续失败。
- 支持单词条建议、已有词库重新扫描和管理员逐条处理。
- 原始词条不可被 Agent 修改；朗读变体必须单独存储。

## 角色与权限

老师 Agent 只读失败上下文并提出结构化建议；管理员可接受、拒绝、修改或标记误判。系统 Agent 不参与即时判分修复。所有工具调用带 `analysis_id`、操作者和审计记录。

## 人类评价

`accept_suggestion`、`accept_transcript`、`reject_suggestion`、`edit_and_apply`、`mark_asr_error`、`defer`。低风险的单条朗读变体可由一次评价直接实施；删除变体、修改原词和批量操作必须二次确认。

## 变体规则

确定性规则优先：`sth/something`、`sb/somebody`、`etc/e t c/et cetera`、`ASAP/a s a p/as soon as possible`，以及已批准的同音词。LLM 只能提出候选，不能自行生效。

## 验收门

失败事件幂等、迟到结果不重复处理；教师 Agent 不可阻塞课堂；管理员操作可审计；实施后重新跟读立即使用变体；Agent 或模型不可用时显示确定性诊断。
