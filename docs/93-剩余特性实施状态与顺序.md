# 剩余特性实施状态与顺序

更新日期：2026-11-24。本文对照当前代码和 `docs/90`–`docs/93` 后继规格更新；早期 SDD/评审记录保留为历史证据，不应单独视为当前状态。

## 已完成的代码闭环

- 词库导入、发布后会自动扫描发音变体；管理员可以手动重扫。规则变体供跟读判定复用，词条朗读使用统一 speech normalization。相关入口在 `server/internal/api/router.go`、`teacheranalysis.go` 和 `teacheranalysisroutes.go`。
- 跟读失败会幂等写入分析记录并排入持久任务；管理员可触发确定性诊断、查看建议并提交评价。该流程不阻塞课堂快路径。当前分析 worker 由管理员端点触发，不是后台常驻模型 Agent。
- Pilot Room 运行时已接入受控课堂 API 的进入、命令提交与收据返回；通过 `runtime=pilot` 显式选择，默认仍走 legacy Room。两种运行时保持隔离，尚不能把可选 Pilot 路径表述成默认课堂迁移完成。
- TTS 预生成/缓存、管理员模型配置、远程驻留执行器协议与本地 CLI 已实现；Go 全量、race、前端构建及相关 Playwright 回归记录见 `docs/90-自动验收收尾记录.md`、`docs/93-TTS远程驻留执行器规格与SDD.md` 和 `review/` 对应证据。

## 尚未完成或需要外部验收

1. **生产 Pilot 推广**：当前 Pilot 是显式 opt-in 路径。若要设为默认课堂，仍需完成剩余隔离 SQLite/双进程旅程、复位竞态及运行环境准入矩阵，并明确回滚方案；历史设计中未通过的门不能以单测替代。
2. **Pinned VFS golden 提案**：`review/pilot-vfs-golden-human-review-20261022.md` 标记为 `BLOCKED_STALE_SPEC_BINDING`：提案绑定的 docs/55 哈希不是当前设计版本。不能直接晋升候选 golden；需按当前规格重新生成源绑定证据并复核，之后由 l17728 完成人工签署。
3. **远端驻留设备实测**：代码和自动化通过不等于真实远端 Model Console 的 TLS 连通、模型能力/时延和长期稳定性已验收。正式接入不得使用 HTTP 或上传真人音频到未批准端点。
4. **真人课堂声学/多设备**：外放回声、背景人声、键盘噪声、多人并发及首音/打断长尾仍需现场测量；真人试点尚未完成。
5. **人工听感验收**：TTS 合成样本的听感与中文/英文音量平衡需由人试听。自动 WAV/协议检查不能替代听感结论。
6. **覆盖率质量门**：`docs/91-TTS素材预生成SDD.md` 记录过 API 包整体覆盖率 77.5%，低于项目 80% 门槛。后续全量测试/race 通过不等于覆盖率已达标；需要在当前树重新测量并补足实际缺口后，才能关闭该门。

## 暂缓及不作为当前闭环阻塞

- 观察员 Agent、完整 Agent 运营督导后台、考前冲刺以外的扩展目标模式、词组/语法内容插件属于后续产品路线图。
- 云端 ASR、WebRTC 降噪/回声消除属于可选增强。当前业务应先保持本地识别、确认后的课堂决策和明确文字降级；启用云端服务前须完成供应商/传输安全审查。

## 收尾顺序

先完成隔离 Pilot 自动化准入与 Linux/生产环境证据核对；再连接真实远端合成服务并做公开样本容量测量；最后安排真人声学试点和人工听感签收。发现代码缺陷时先补逻辑测试与 Playwright 用户旅程，再更新对应规格和验收记录。未进行的真人或外部环境验收应明确标为未验收，不得以构建、交叉编译或模拟服务通过代替。
