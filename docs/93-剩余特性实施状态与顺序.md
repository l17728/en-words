# 剩余特性实施状态与顺序

更新日期：2026-11-24。本文对照当前代码和 `docs/90`–`docs/93` 后继规格更新；早期 SDD/评审记录保留为历史证据，不应单独视为当前状态。

## 已完成的代码闭环

- 词库导入、发布后会自动扫描发音变体；管理员可以手动重扫。规则变体供跟读判定复用，词条朗读使用统一 speech normalization。相关入口在 `server/internal/api/router.go`、`teacheranalysis.go` 和 `teacheranalysisroutes.go`。
- 跟读失败会幂等写入分析记录并排入持久任务；管理员可触发确定性诊断、查看建议并提交评价。该流程不阻塞课堂快路径。当前分析 worker 由管理员端点触发，不是后台常驻模型 Agent。
- Pilot Room 运行时已接入受控课堂 API 的进入、命令提交与收据返回；通过 `runtime=pilot` 显式选择，默认仍走 legacy Room。两种运行时保持隔离，尚不能把可选 Pilot 路径表述成默认课堂迁移完成。
- TTS 预生成/缓存、管理员模型配置、远程驻留执行器协议与本地 CLI 已实现；Go 全量、race、前端构建及相关 Playwright 回归记录见 `docs/90-自动验收收尾记录.md`、`docs/93-TTS远程驻留执行器规格与SDD.md` 和 `review/` 对应证据。
