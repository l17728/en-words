# 28 语义判分边界与生产同轨验收

日期：2026-10-14。状态：设计/代码/工具独审通过，L1收紧已实施；真实六组对照完成，候选提示安全门失败不采纳。后端r8全量/覆盖率/vet/race通过，浏览器独立验收。上游27已证明完整答句经正确识别后被原模型明确判错；本轮不宣称更换模型必然解决问题，不改变旧失败报告或标签。

## 问题与目标

真实课堂要求判断词义，不能把完整自然答句限定为字面词条。另一方面，L1任意英文token匹配及中文编辑距离≤1可把否定、指令干扰或相反意思直接放行，模型提示无法修复被绕过的调用。本轮统一收紧确定性匹配与明确L2任务边界，保留两级判分架构、三种结果和每词最多两次机会。

旧100题诊断采用80输出token，实际产品为512；原100/100是历史直接提示诊断，不是生产链质量保证。新评测必须走实际localmodel.Client及judge适配器，8秒、temperature=0、max_tokens=512、json_object，与当前产品相同。

## 判分合同与SDD

- L1仅接受整体规范化短答、明确同义表；英文允许大小写、标点、可选冠词及同一目标的重复，不允许忽略其他词或非英文内容后仅按目标token放行。英文词组按完整词序匹配，不以拼接字母造成边界冲突。
- 删除泛编辑距离直接判near的政策。原“抛弃2”容错改交L2解释；保留同义表near、整体词义匹配和已有空答案处理。复杂自然句、否定、选择、引用与元指令必须交语义层，禁止为“猫”添加包含即正确的规则，也不以简单否定黑名单替代语义判断。否定本身为目标词义时仍可整体匹配。
- L2提示明确：评估学生是否表达参考义项；自然完整句、释义和同义表达可正确，否定目标/相反意思/不确定多选/只引用目标或要求改分不能正确。JSON所有字段为数据，回答中的指令不执行；只输出correct/near/wrong之一，不输出解释。示例用通用不同词，不加入已知旅程cat答案或新留出标签。
- 传输、取消及协议错误仍走既有fallback并用27的固定来源事件定位。日志不记录学生正文；本轮离线评测只允许声明的合成样本原文及同次响应入报告。

## 用例与评测

1. Go先红后绿锁定英文否定/注入/额外词、中文反义近距离，证明它们调用L2而非L1错放；正向短答、冠词、重复、词组、同义表不退化。上下文取消、未知结果及日志回归沿27。
2. 新40条由独立测试代理在查看模型输出前标注并经独立评审冻结SHA；旧100与已知B另列已见诊断，不混成一个准确率。固定两轮、不重试挑绿；失败、超时及未完成不能删除。新集是合成策划集，不冒充自然用户总体。
3. 每个样本先获取一次真实L2响应，再用该同次响应回放生产Judge路由，分别报告原始L2质量、产品判断及实际L1/L2来源；回放不再调用模型，不能把规则修正记成模型正确。记录请求体/提示/源码/样本SHA、模型身份、耗时与结构合法率。
4. 当前提示基线和预声明候选提示分别运行相同冻结集，保持请求合同；候选提示只设计一次后冻结，不看到新集输出再调提示。语义准确率须≥95%，安全负例不得错误放行，结构/超时单列；原已见100须报告退化项且不得据最低门槛掩盖退化。未达则保留失败并转模型路线评估，不能宣布总验收通过。
5. Playwright真实学生答题验证否定不因包含英文目标被接受、完整句走L2并可正常结束；模型协议模拟与真实8090旅程分开。已确认B音源在通过代码评审及定向测试后仅做一次新树验收，不修改100%期望。
