# 学习统计接入规格与 SDD

日期：2026-10-13。状态：经独立测试/后端评审，以下修订后批准实施，尚未验收。对应 09 中 Stats 占位页缺口。

## 目标与口径

学生从课程表进入 `/stats`，看到自己的真实学习进展、最近课程首答率和连续学习天数。管理员及其他学生不得查询指定学生的统计；本增量不提供跨学生报表。

词数以“学生＋词库＋词条”卡片计数，同一词在不同词库不合并。`learned` 为 learning＋graduated，`graduated` 为其子集；`remaining` 为 new；`placement_known` 为 mastered，单列以免把摸底已会冒充教学成果。页面说明统计仅含当前已选词库，移除词库遵循现有删除进度行为。

课程仅计 `finished` 且有 FinishedAt、时间不晚于本次 Clock.Now 的记录；课程数、近期列表及连续天数使用同一合法集合。最近 20 课按完成时间倒序，同时间按课 ID 倒序，展示词数与首答率（不是最终答对率）。连续学习天数基于全部合法历史，按 Asia/Shanghai 自然日去重；若今天未学但昨天有课，从昨天向前连续计数；既无今天也无昨天则为 0。采用当前产品适用的固定 UTC+8 时区，不依赖 Windows 系统 tzdata，不涉及历史夏令时换算。无数据返回数字 0、空数组，不生成示例数据。

## API 与一致性

新增 `GET /api/v1/student/stats`，身份仅来自认证 claims，不接受 student_id/book_id 覆盖。返回 `learned/graduated/remaining/placement_known/finished_lessons/streak_days/timezone/recent_lessons`；recent 每项包含 lesson_id、book_id、finished_at、total_words、first_try_rate。

SQLite 模式在单个只读工作单元中读取当前学生卡片、课程及最近课程的 RuntimeRecord 课报，避免同次返回混合不同结课版本；不得调用会再次拿数据库连接的全局服务。内存模式读取仓储副本，不承诺跨多服务严格事务快照。课报缺失、损坏或读取失败应显式返回错误并记录 trace，不能把存储故障显示成空统计。未完成课不要求课报。

仅为统计读取增加必要的仓储访问器，直接传播 StudentBooks/ListCards/ListLessons 错误，不复用会吞错的 StudentLessons/repoLessonsAll；不修改卡片、配置、课报或排课。只读取最近20课的课报；缺 report 对象、total_words 非正、首答率超出 [0,1] 或非有限数视为语义损坏，旧课不读取课报。日志 `stats_loaded/stats_load_failed` 含 trace、student_id、计数/错误类别，不包含学生作答和记忆原文。

## 前端

课程表增加“学习统计”入口；统计页提供返回课程表、加载中、无数据、错误和重试状态。词数用带语义标签的统计卡，最近课程用可访问表格展示首答率变化，避免引入图表依赖。说明首答率与已学词数口径；响应晚到或页面卸载后不覆盖新会话数据。失败时保留明确错误，不显示伪造的全零结果。
