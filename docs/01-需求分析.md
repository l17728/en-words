## 1. 项目概述

### 1.1 项目定位

一个面向个人/家用场景的英文单词学习 Web 软件。区别于传统背单词应用的核心特征：

1. **AI 老师真人授课**：学生打开课程后，服务端"老师 Agent"实时驱动课堂——展示单词、朗读、出题、判分、鼓励、控节奏，学生只需跟着屏幕学。
2. **双智能体平台**：系统本身具备智能（系统 Agent 负责排课、评估、调参），老师 Agent 负责课堂授课；两者都通过统一的**工具注册表（Tool Registry）** 以 function-calling 方式操作平台全部能力。
3. **协作软件形态**：每节课的 UI 由学生和老师 Agent "共同在场"——Agent 调用 API 模拟点击操作 UI，学生按 UI 显示学习。
4. **科学记忆调度**：依据《别再被艾宾浩斯曲线"骗了"》（zhuanlan.zhihu.com/p/2028560112931850023）的核心结论——**等间隔复习**优于流行的"前密后疏"艾宾浩斯周期表；间隔效应 + 分散练习才是正道。
5. **反馈驱动自适应**：学生可随时反馈（太多/太难/某天有事），系统 Agent 在配置边界内自动调整单词量、频率、推迟课程。

### 1.2 系统组成（四层架构）

```
用户层      学生 / 管理员
智能体层    老师 Agent（课堂） · 系统 Agent（教务）
开放能力层  Tool Registry（工具=带Schema的API能力，按角色作用域授权）
平台层      课堂运行时 · 调度器 · 配置中心 · 学习记录 · 词库 · 反馈中心 · 认证 · TTS/ASR
```

### 1.3 范围

- **范围内**：Web 应用（桌面浏览器优先）、词库管理、课堂教学、学习记录、排课调度、反馈闭环、双 Agent 运行时、工具注册表、TTS/ASR/LLM 的 Mock 与可替换接入。
- **范围外**：移动原生 App、多租户 SaaS、社交功能、离线使用、真实支付。

## 2. 角色定义

| 角色 | 类型 | 职责 | 使用界面 |
|---|---|---|---|
| **学生** | 人类 | 选词库、摸底标记、上课学习、跟读作答、提交反馈 | Web UI |
| **管理员** | 人类 | 词库 CRUD、批量导入、账号管理、查看全局配置与审计 | Web UI（管理后台） |
| **老师 Agent** | LLM 智能体 | 课堂内实时授课：控节奏、发指令、朗读、出题、判分、鼓励、抽取话术 | 通过 API/工具操作协同 UI，无独立界面 |
| **系统 Agent** | LLM 智能体 | 课后教务：生成/调整学习计划、评估学习效率、处理反馈、调整参数、逾期重排 | 通过 API/工具操作平台，可向学生发通知消息 |

> 关键理解：**两个 Agent 都是"软件用户"**，与人类用户一样登录系统（服务账号），通过开放能力层的工具操作平台。Agent 的行为边界由工具作用域（scope）和参数边界（bounds）约束，全部操作留审计。

## 3. 术语表

| 术语 | 定义 |
|---|---|
| 词库（WordBook） | 一个学习范围的单词集合，如"初中""高三"。每个词库独立拥有一套学习计划，互不影响。 |
| 词条（WordEntry） | 词库中的一条：单词、音标、词性、**简明中文释义**（匹配该词库教学深度）、例句。 |
| 摸底（Placement） | 选词库后、排课前的一次性流程：每屏 100 词只显示英文，学生标记"已会"的词。 |
| 课程（Lesson） | 一次学习会话，处理一个批次（Batch）的 50~100 词。 |
| 批次（Batch） | 课程要学的词集，从"未学会"词池中按调度策略抽取。 |
| 组（Group） | 课内的最小教学单元，固定 5 词。 |
| 小测（Quiz） | 每组教完后对本组词+随机已学旧词的测试。 |
| 综合测试（Review Test） | 从第 2 组起，每组教完后对**此前所有组**的词打乱测试；以及课程结束时对全批次的完整测试。 |
| 毕业（Graduated） | 一个词在测试中连续答对 N 次（默认 2 次）后退出后续测试池。 |
| 掌握状态（Mastery） | 每生每词的状态：`new / learning / mastered / graduated` + 错误次数 + 对错历史。 |
| 等间隔复习 | 背完→次日复习→再次日复习……间隔固定的复习策略（本文档引用文章的核心结论）。 |
| 间隔阶梯（Interval Ladder） | 等间隔策略的参数：`[1d,1d,2d,2d,4d,7d,14d,30d]` 之类的固定间隔序列，可配置。 |
| 工具（Tool/Skill） | 开放能力层注册的平台能力单元：名称+描述+JSON Schema+作用域+风险级。 |
| 话术库（Script Bank） | 预置的教学话术集合（开场/转场/鼓励/纠错/下课），Agent 抽取后做口语化微调再呈现。 |
| VAD | Voice Activity Detection，前端语音活动检测，用于判定学生"跟读完成"。 |

## 4. 核心业务流程

### 4.1 管理员：词库管理流程

```
管理员登录 → 词库列表 → [新建词库(名称/学段描述)]
  → 单条增删改查词条
  → 批量导入：粘贴文本/上传文件（每行 "word 释义" 或自由格式）
      → LLM(mock) 解析：抽取单词、匹配学段简明释义、补全音标/词性/例句
      → 预览解析结果（可人工修正）→ 确认入库
  → 发布词库（对学生可见）
```

**释义要求**：词条释义必须是"该学段学生应掌握的最常用简单释义"，一条为主，不用字典式多条堆砌。如高二词库中 `address` 只取"n. 地址"，不列"v. 演说；处理"等。

### 4.2 学生：选库与摸底流程

```
学生登录 → 词库广场 → 选择词库（可多词库并行，各自独立计划）
  → 首次进入该词库 → 摸底模式：
      每屏 100 词、仅英文（按词频排序展示）
      → 学生勾选"我已经会的词"
      → 下一屏……直到全部过完
  → 提交 → 系统生成初始学习计划（第一课时间 = 最近可用时间）
```

### 4.3 学生+老师Agent：课堂学习流程（核心）

```
到课程开放时间 → 学生在课程表点击"进入课堂"
  → 后端创建课堂会话，老师Agent与学生通过同一 WebSocket 加入
  → 老师 Agent 逐组授课（每组 5 词）：
      [组内逐词教学]
        1. 显示单词（仅英文）→ 学生点击 → 发音（TTS 读 3 遍英文，每遍间隙约 1.5s）
        2. TTS 读 1 遍中文释义
        3. 学生跟读 3 遍（前端 VAD 判定每遍完成；按钮+超时兜底）
        4. 老师 Agent 过渡话术 → 下一个词
      [组内小测]
        5 词教完 → 小测：本组词 + 随机已学旧词（数量可配置，默认 3）
        测试时英文界面不显示中文；学生语音作答 → ASR 转写 → LLM 判分（对/错）
        答错 → 重复学习（R2-AI-01 明确：完整教学闭环 = 重显中文释义 + 朗读英文 + 
               中文释义朗读 + 跟读 3 遍）→ 再测同词，直至答对
      [综合测试]（从第 2 组起，每组教完后）
        此前所有组的词打乱测试；答对的打勾、不再出现在下轮综合测试
        答错的打叉 → 回顾环节：逐词过一遍（看中文+听英文朗读）→ 重测至掌握
  → 全部组完成 → 课程完整测试（本批次 50~100 词）
      会的打勾，不会的打叉 → 对打叉的复习 → 重测
  → 下课：老师 Agent 总结+鼓励 → 课堂结束 → 触发系统 Agent 排下一课

**长课续课**：单次学习会话超时（默认 60min）或学生中途退出 → 进度自动保存，课程转为
`in_progress_paused`，学生下次进入从断点继续（已完成词不重学，已判分题不重判）。
**话术定位**（R2-FE-01）：老师话术仅用于 UI 呈现与陪伴，**不驱动状态机**——流程推进由平台
状态机按决策表确定性执行，话术由 LLM 异步生成、超时降级模板原文。
```

**节奏要求**：老师 Agent 保持稍快节奏，不停顿过长（每个等待动作有超时兜底，超时后温和提醒并继续）；根据学习效果穿插鼓励话术。

### 4.4 系统 Agent：排课与调度流程

```
触发源：结课事件 / 学生反馈 / 逾期检测（定时任务每 30min）
  → 读取该生该词库的学习记录（每词掌握状态、错误次数、课堂表现）
  → 生成/调整学习计划：
      只排"下一次课程"的时间与批次内容，但完整计划视图对学生可见
      时间 = 上次课程时间 + 当前间隔阶梯值（等间隔策略）
      批次 = 未毕业词 + 到期复习词，数量取配置 wordsPerLesson(50~100)
  → 课程到达开放时间才可进入
  → 逾期未上课（超过开放时间 N 小时，可配置）→ 评估重排：
      顺延至下一天同时段，间隔阶梯不前进（复习窗口错过则本阶重走）
```

**依据文章的调度原则**：
- 不使用"20min/1h/1d 前密后疏"周期表；
- 采用**等间隔**：间隔阶梯 `1d,1d,2d,2d,4d,7d,14d,30d`（默认值，可配置），即第1、2课连着两天，之后逐步拉长；
- 目标导向：若用户目标设为"考前冲刺"，阶梯整体压缩为全 1d；"长期记忆"用默认阶梯；
- "记忆保留"含义：错过的复习不视为清零，重走当前阶梯一级即可（省力再学）。

### 4.5 反馈闭环流程（新增）

```
学生提交反馈（课堂内快捷按钮 / 课程表页面表单 / 课后推送）
  → 系统 Agent 解析意图（LLM mock → 意图分类 + 参数抽取）：
      A. 减量："每天太多了"        → 调 wordsPerLesson（边界内下调，如 80→60）
      B. 加量："太简单了想多学点"   → 调 wordsPerLesson 上调（≤100）
      C. 频率："我想每天两次"      → 调 lessonsPerDay（≤2）
      D. 推迟："周三有事"          → 推迟指定日期课程至次日/指定日
      E. 难度："这个词太难记"      → 标记该词加强（下次课优先+增加测试频次）
      F. 投诉/异常："发音不对"      → 记录工单转管理员，回复学生已记录
      G. 无法自动处理             → 转人工（管理员待办）
  → 在配置边界内执行调整（超边界的建议需学生确认或转管理员）
  → 回复学生调整结果（自然语言，来自话术库+口语化）
  → 全程审计（谁/何时/改了什么/依据哪条反馈）
```

### 4.6 双 Agent 与开放能力运行流程

```
平台启动 → Tool Registry 加载全部工具定义（Schema/Scope/Risk）
老师 Agent 运行时：
  事件循环：课堂事件(学生点击/组完成/测试结果/超时) → 组装上下文
    → LLM 决策（输出：话术文本 + 工具调用序列）→ 校验作用域与参数 → 执行
    → 通过 WS 推送 UI 指令给学生端
系统 Agent 运行时：
  触发（结课/反馈/逾期定时）→ 读取数据 → LLM 决策 → 工具调用（排课/调参/回复）
```

## 5. 功能需求（FR）

### FR-C 选库与摸底

| 编号 | 需求 | 优先级 |

### FR-D 课堂教学（老师 Agent + 学生协同）

| 编号 | 需求 | 优先级 |
|---|---|---|
| D1 | 课程到开放时间才可进入；课程表显示全部计划课程（未到的置灰+倒计时） | P0 |
| D2 | 课堂会话：学生与老师 Agent 共用同一 WS 频道；Agent 指令驱动 UI | P0 |
| D3 | 批次切分：本课 50~100 词（可配置）分为 5 词/组 | P0 |
| D4 | 逐词教学：点击单词 → TTS 英文读 3 遍 + 中文释义读 1 遍 | P0 |
| D5 | 学生跟读 3 遍：前端 VAD 判定每遍完成（环境噪音基线+动态门限+尾静默判定），按钮+超时兜底 | P0 |
| D6 | 组内小测：本组词+随机旧词；题目仅英文；学生语音作答 | P0 |
| D7 | 小测判分：ASR 转写 → LLM 判分（对/错/近似对），mock 期用固定脚本 | P0 |
| D8 | 答错处理：重显中文释义 → 重复学习 → 再测，直至答对 | P0 |
| D9 | 综合测试：第 2 组起每组教完测此前所有组词（打乱）；答对打勾毕业出池，答错打叉回顾后重测 | P0 |
| D10 | 回顾环节：逐词显示中文+TTS 朗读英文 | P0 |
| D11 | 课程完整测试：全批次词；打勾/打叉；打叉复习重测 | P0 |
| D12 | 节奏控制：每个等待步骤有超时（可配置），超时温和提醒后推进；不停顿过长 | P0 |
| D16 | **课后学习报告**：每课结束自动生成结构化课报并由老师 Agent 输出人格化总结——① 教学评价（本课表现亮点/薄弱点）② 学习建议（下节关注点）③ 总体进展总结（累计词量/毕业词/正确率趋势）；系统 Agent 结合**记忆曲线对照**（到期复习完成率/逾期词数/阶梯健康度）审视并调整计划（详见 04 §4 S-13~S-15 与话术 RB 系列）。**课报必须包含量化统计（数字表）与定性总结（文字评语）两部分**（用户要求 2026-08-23） | P0 |
| D17 | **全程语音操作**：除键鼠外，全流程可用语音操作——① 课堂内教学指令（下一个/跳过/暂停/退出/我读完了）② 测试作答 ③ 教学反馈（学生随时口头说"太多了/周三有事"直接进反馈闭环）④ 页面导航（首页/课程表/开始学习）。课堂内走 Omni 转写流，课堂外走浏览器 Web Speech 本地识别；语音指令为**确定性词表匹配**（不经 LLM，误识别率低）；键鼠始终保留（语音为增强非替代） | P0 |
| D13 | 话术系统：开场/转场/鼓励/纠错/下课话术从话术库抽取+口语化微调（加昵称、语气词） | P0 |
| D14 | 断线恢复：学生刷新/断网重连后课堂状态不丢失，可继续；会话超时/主动退出可**续课**（断点继续，不重学） | P0 |
| D15 | 学生可主动跳过跟读/某词（记录，视为待复习） | P1 |
